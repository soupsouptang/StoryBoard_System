# 下一代通告与导出设计

2026-10-05。仅下一代规划，模板和服务从零设计，未启动实现；不复制旧模板、个人资料或用户素材。输出文字禁止附免责声明。

## 1. 动作与事实

拍摄日/方案 → 生成草稿 → 检查缺项与来源 → 预览纸张/个人投影 → 明确发布固定修订 → 明确发送 → 分别查看通知、送达、阅读、确认和到场。自动联动只能更新草稿/差异/需重确认范围；不能自动发布或外发。“一键发布并发送”仅是有权者在预览范围后明确启动的两个动作，分别记录结果，发送失败不回滚既有发布。

一键生成今日草稿、沿用本人授权模板、预览和下载减少重复选择；正式交付、发送、永久删除不是无提示快捷动作。渠道未配置返回真实缺项并允许授权下载，不伪造送达。旧确认属于旧修订，新时间或地点的重要变化按规则再次确认；单纯重新生成 PDF 不制造新业务修订。

## 2. 纸张信息排列

页头三分区：左为项目/制作单位及必要联系人，中为标识、日期、拍摄日、摄制组和大号集合时间，右为有实际来源的天气/日出日落/医疗点。未知资料可省略或待确认，医院不自动宣称最近，天气附来源/观测或预报时刻。总拍摄日未知不填总数。总体集合与个人/部门集合不是同一字段。

页头之后依次为紧凑部门集合表、主要地点和集合点、当日安排、演员准备和工作日程、必要工作人员、器材道具需求、实际录入的准备备注、变化摘要。无数据区块按模板省略，必需缺项仍阻止发布；不为了填满页面复制示例数据。

| 当日表字段 | 排列及语义 |
| --- | --- |
| 时间/类型 | 真实安排的当地日期及起止；跨午夜标次日；准备/拍摄/转场/休息分开 |
| 场景/镜头 | 稳定身份显示号，重复安排不生成新创作对象 |
| 内外景/昼夜 | 显式值或有效场景来源；冲突附提示，不猜 |
| 描述/地点 | 描述可换行，地点明确集合/拍摄差别 |
| 角色/人员 | 显示引用号有图例；字段授权决定是否公开个人姓名/电话 |
| 页数/预计拍摄时长 | 固定剧本版本的页占比与预计劳动时间；不是成片时长 |
| 准备/备注 | 当前有效需求，不写库存或虚构完成 |

场景页占比可显示八分之一单位仅当来源解析可靠；不同版本分页不相加。同场景多次安排不重复计唯一剧本页数；拍摄次数、按安排覆盖和未知项单列。日末汇总区分唯一场景页数、拍摄工作、准备、转场、休息、计划跨度与未知，不把所有持续时间简单加成工作工时。

## 3. 模板与分页

提供 A4竖版210×297mm、A4横版297×210mm、Letter竖版215.9×279.4mm和A3横版420×297mm提案，纸张方向、拍摄画幅和图框比例独立。页边距建议12mm；正文9.5—11pt、标题16—20pt、页脚8—9pt，实际长中文样例验收后确定，不缩小整页凑一页。

续页重复身份、日期/组、修订和表头；长备注续页附条目身份，标题与首行保持同页，签名/确认不凭排版生成事实。照片等比、有效构图、适配后填黑，竖图框竖起。深色 UI 与白纸模板分开渲染；灰度打印依靠文字和边界，不靠彩色理解。

地图可选：只有授权坐标/地址及已配置服务才显示路线入口或实际地图，不复制参考图地图截图。纸张不能嵌服务时保留文字地址和有权在线入口；地点、联系人按接收投影裁剪。地图附件和医院记录版本固定到发布来源。

## 4. 个人手机页

首屏顺序为项目/日期/组/修订 → 本人集合大号时间 → 重要差异 → 地点/准备 → 确认指定修订。总集合和个人时间并列时明确标签。地图、联系方式和原版下载均重新授权；展开不暴露他人私人字段。

按钮说明“确认已阅读此修订”，不是到场、开工或审阅批准。离线/失败保留未上报状态，收到服务器回执才完成；页面打开最多记录查看，不能代写确认。撤销/到期有友好说明，已下载副本不能假称收回。

## 5. 输出种类

| 类型 | 建议格式 | 关键范围 |
| --- | --- | --- |
| 通告及个人通告 | PDF、Word、授权HTML | 同一固定发布修订，不复制手机正文 |
| 排期条带/日计划 | PDF、XLSX | 指定方案、日期范围、当前/基线/预测明确，日末汇总 |
| 演职人员工作日表 | PDF、XLSX | 指定方案、人员/角色关系、日期图例、未知和暂定分开 |
| 时间段器材道具需求 | PDF、XLSX、CSV | 数量、时段、型号、来源、共用组，无库存 |
| 横竖分镜表 | PDF、Word、XLSX | 字段模板、图框、构图、时码和描述 |
| 视觉墙/九宫格/单镜详情 | PDF、Word | 固定对象顺序、比例和长字段续页 |
| 好莱坞式剧本/制作分镜 | PDF、Word | 场景标题、动作、角色、对白、分页及明确映射 |
| 后期任务/依赖 | PDF、XLSX | 输入输出版本、主责、阶段、依赖及计划/实际 |
| 工程阅读和恢复 | PDF、JSON清单与媒体ZIP | 新版格式版本、校验、工程QR/DM分片、允许媒体 |
| 剪辑交换/字幕 | EDL、FCPXML、OTIO、SRT、VTT | 成熟工具，帧率与时码、真实导出回读测试 |

工作日表可显示首次工作/工作/最后工作等中文标签，派生自指定方案明确安排；“旅行/候场”只有来源事实才输出，横线不能暗示中间日期连续工作。兼任按人员去重，按角色展开是明确另一个口径，页首写清。

剧本正式正文与讨论分开，默认不印批注；可另选固定版本的批注附录，包含场景/段落锚点、作者允许标签、状态和引用版本。新旧版本左右差异只属比较报告，不印成正式对白。角色名、动作、对白与续页名同源，中文字体和混排需真实文件验证。

## 6. 字段、版本和权限

字段模板引用稳定字段键，选择包含/顺序/显示标题/格式/允许范围，纸张列宽不使用网页共享列宽。生成预览包含省略项、敏感字段、缺图和失效列；永久删除列不能用旧模板复活。固定模板版本、业务来源、有效构图、请求人、接收投影、水印和渲染器版本。

生成、作业执行、结果打开和下载分别校验权限及删除状态；缓存含授权投影和固定来源，不按标题缓存。Word/XLSX外部编辑不回写业务，重新导入走预览与命令。预览24小时、可重建下载7天，项目可缩短；正式发布/交付不套临时工件期限。

## 7. 工程码和水印

工程 QR/DM 按分片序列含格式版本、导出/快照身份、序号/总数、压缩类型、片段与整包校验、允许恢复清单。大型媒体通过受控附件与相对路径，不能假称所有原图塞进码；缺片、乱序、重复、混包、未知版本和解压规模先检验再预览导入。码不含密钥、登录/下载令牌、私人联系人或内部地址。

可见水印支持增删改及位置，隐写追踪独立验证；元数据、文件名、二维码不能当隐写。实测像素解码、中心/边角裁剪、多比例重框选、截图分辨率、压缩、灰度与无水印对照，记录恢复和误识别。限制写测试报告，不附到导出正文当免责声明。

## 8. 独立实现与验证

排期、发布、通知、字段投影、文档渲染、工程编码、隐写和正式交付各自负责，不合成一个巨型模块。新实现选成熟库，不继承旧渲染服务或模板。先合成项目验证固定请求与权限，再验证实际文件与回读，最后端到端发布/发送失败定向重试、重要改期、旧确认、撤权、永久删除迟到作业、返工和交付退回。当前仅设计，不宣称任何模板已通过。
