日期：2026-10-05。状态：**结构审核稿，尚未确认，未批量应用**。

大类以[工种目录、制作分工与岗位添加定义](JOB_CATALOG_DEFINITIONS_2026-10-05.md)为准。本例归 D「实拍：摄影、灯光、录音与现场」，再细分摄影机及其资料。制作分工和实际任职不当作器材分类层。

**只改组织结构，沿用仓库已有参数，不重新核验、补值或升级来源状态。** 相机型号和字段的原始资料本轮不改写。不再限制分类为四级；需要几个清楚的层级就展开几个，不为凑层数添加空节点。

## 1. 总：摄影机这一小类包含什么

摄影机资料描述机身的成像、录制和工作能力。先选择本小类内的品牌和型号，再阅读对应分项，最后查看字段及其值。

固定镜头设备按真实内置成像模组展开；可换镜头机身记录自身原生卡口。镜头、滤镜、遮光斗、监视器和电池仍属于各自器材小类，摄影机只引用需要核对的接口或支持关系。

## 3. 各分项的边界

| 分项 | 支持内容 | 字段放置方式 |
| --- | --- | --- |
| 传感器 | 整块传感器的规格 | 宽、高和有效像素归本项；某模式使用的有效区域另放录制模式 |
| 镜头卡口 | 机身原生连接条件 | 卡口与已验证的镜头/转接支持关系分别查看 |
| 录制格式 | 该型号的格式支持 | 共用格式定义只引用；型号在什么条件下支持另记录 |
| 录制模式 | 指定模式的参数组合 | 输出尺寸、有效区域、格式、帧率和数据率随具体模式记录 |
| 记录介质 | 介质类型及支持条件 | 具体卡的资料和官方名单属于关联资料 |
| 监看 | 机身显示能力 | 外部监看信号从对应端口资料读取，不冒充录制规格 |
| 机身端口 | 视频、音频、同步、控制等各端口的功能 | 各用途分开显示，不能由接口外形推定全部功能 |
| 供电 | 电源输入及条件化续航 | 引用独立电池或供电设备资料 |
| 物理规格 | 尺寸及重量 | 数值附单位和测量范围，不把附件重量自动加进机身重量 |
| 配件支持 | 宿主、功能和限制 | 配件自己的型号、参数不搬到摄影机字段里 |
| 资料来源 | 现有来源和核验状态 | 沿用原记录，不因重排目录标记为新核验 |

上述字段来自现有合同。尚未填值与不支持、未知、不适用分别表达，不因为案例没有展示就删除字段。
