# 知识目录：工种大类、小类与字段

版本：2.0，2026-10-05。用户已确认摄影机、镜头运动及字段—岗位案例，并要求按同样总分结构整理全目录。本篇和分册都是下一代规划，尚未实施。

## 1. 分类规则

大类直接取[工种目录、制作分工与岗位添加定义](JOB_CATALOG_DEFINITIONS_2026-10-05.md)的 A–H。先细分知识小类，再细分真正的下级类型、资料分项和字段。层数不固定，也不为凑层数增加空项。

类别、类型、品牌、型号、字段和值各有明确身份。景别下面是远景、中景等类型；镜头运动下面区分转动、位移和组合运动，再按具体类型展开字段。构图、运镜、机位、摄影角度、视场角、透视、人物调度、轴线和拍摄准备各自维护。留白相关条目取消。

制作分工、岗位任职、知识分类和权限各自维护。工种原大类名称保留；新增小类标题只表达一种内容。中文名称必须有，技术键可英文。独立对象之间使用有类型、有中文原因和条件的关系，不因浏览层级成为业务所有者。

## 3. 器材、软件和格式的展开

| 内容 | 必须逐层展开 |
| --- | --- |
| 器材 | 工种大类 → 器材小类 → 本类品牌 → 型号 → 变体或真实内置模组/模式 → 资料分项 → 字段 |
| 软件 | 使用该软件能力的工种大类 → 专业小类 → 软件厂商 → 产品 → 适用版本 → 能力项 → 产生/消费/导入/导出/转换方向 → 支持条件 |
| 格式 | 专业小类 → 格式类别 → 格式身份 → 结构或配置版本 → 独立参数 → 产品支持关系；一份格式定义可以被多工种引用 |

软件和格式的共同字段、类型及专业消费者见[字段路径](knowledge/SOFTWARE_FORMAT_FIELD_PATHS_2026-10-05.md)。

器材的厂家、型号、参数值、宿主名单和直接配对只在[真实数据样例](REFERENCE_SEED_DATA_2026-10-05.md)填写。分类页不填真实产品值，不建立混杂接口和品牌的总库。

## 4. 字段的内部结构

| 字段类型 | 继续展开 |
| --- | --- |
| 尺寸 | 长、宽、高、单位、测量对象分别可读 |
| 数值范围 | 下界、上界、单位、边界包含方式；未知边界与零分开 |
| 测量表 | 每行保存测量条件、值、单位、来源定位；不把一行扩大到全部配置 |
| 支持关系 | 宿主/附件/端口身份、工作方向、功能、模式、版本、必要部件、限制、逐项状态及证据 |
| 业务引用 | 固定业务对象及修订、用途和适用条件；知识库不复制可修改业务事实 |

尚无技术键的知识描述项标为待定，不能为目录整理直接创建数据库列。
