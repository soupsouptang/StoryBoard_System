# 镜头运动案例：按工种大类建立总分结构

日期：2026-10-05。状态：**结构审核稿，尚未确认，未批量应用**。

本例同样归[工种目录](JOB_CATALOG_DEFINITIONS_2026-10-05.md)的 D「实拍：摄影、灯光、录音与现场」。不限制四级，不新增知识编号或改写原字段值。按现有主题的定义整理类别与字段位置。

## 1. 总：镜头运动这一小类包含什么

本例的镜头运动指拍摄或虚拟摄影过程中摄影机位置、朝向随时间变化。先分转动和位移，再分具体运动类型，最后展开该类型的字段。两类运动可以按时间有序组合。

光学变焦、焦点转移、机内裁切、后期重构图各有独立知识内容，通过关系引用。它们不因为会改变画面就被塞进摄影机位移类型。

## 2. 分：类型到字段

```text
D 实拍：摄影、灯光、录音与现场〔工种大类〕
└─ 镜头运动〔知识小类〕
   ├─ 转动〔位置基本不变，朝向变化〕
   │  ├─ 水平摇摄
   │  │  └─ 字段
   │  │     ├─ 运动类型
   │  │     ├─ 起始朝向
   │  │     ├─ 结束朝向
   │  │     └─ 运动时机
   │  ├─ 俯仰摇摄
   │  └─ 滚转
   ├─ 位移〔摄影机位置变化〕
   │  ├─ 升降移动
   │  ├─ 横向移机
   │  ├─ 纵向移机
   │  │  ├─ 字段
   │  │  │  ├─ 运动类型
   │  │  │  ├─ 起始位置
   │  │  │  ├─ 结束位置
   │  │  │  ├─ 运动轨迹
   │  │  │  └─ 运动时机
   │  │  └─ 限定方法
   │  │     └─ 固定焦距的空间推进〔继承纵向移机字段〕
   │  └─ 环绕移机
   └─ 组合运动〔已有转动/位移的有序组合〕
      └─ 按明确顺序引用所用类型，不生成全部排列的新分类
```

树中以水平摇摄、纵向移机展示到字段层；其余具体类型的字段在下表逐项展开。固定焦距的空间推进是下级方法，字段继承纵向移机的定义，不另抄一套。

每个具体类型下再展开它适用的字段：

| 所属类型 | 展开的字段 | 不混入本类的内容 |
| --- | --- | --- |
| 水平摇摄 | 运动类型、起始朝向、结束朝向、运动时机；位置保持条件 | 轨道型号、光学变焦参数 |
| 俯仰摇摄 | 运动类型、起始朝向、结束朝向、运动时机；位置保持条件 | 升降摄影机的位移参数 |
| 滚转 | 运动类型、起始朝向、结束朝向、运动时机；滚转轴说明 | 不把静态倾斜构图当作一段实际转动 |
| 升降移动 | 运动类型、起始位置、结束位置、运动轨迹、运动时机 | 承托设备的型号规格 |
| 横向移机 | 运动类型、起始位置、结束位置、运动轨迹、运动时机 | 人物行动路线 |
| 纵向移机 | 运动类型、起始位置、结束位置、运动轨迹、运动时机 | 光学变焦的焦距变化 |
| 固定焦距的空间推进 | 纵向移机字段，加“保持焦距”的适用条件 | 不新增另一套机位和焦段正文 |
| 环绕移机 | 运动类型、起始位置、结束位置、环绕轨迹、朝向变化、运动时机 | 不强制认定所有环绕都一直朝向主体 |
| 组合运动 | 运动顺序、各段具体类型及各段自己的字段 | 不把多种运动拼成含糊的自由文本值 |

“位置保持”“保持焦距”是定义或适用条件，不是新的大类。“向左、向右”这样的方向取值放进对应类型的字段，不与“镜头运动”“水平摇摄”平排。

## 3. 字段怎样落位

下列字段内容来自已有目录。已有技术键保持；原来只有内容描述、尚无技术键的字段明确标为待定，不为结构审核发明永久字段名。

| 字段 | 现有来源 | 放置方式 |
| --- | --- | --- |
| 运动类型 | `shot.camera_movement`；现有运镜主题 | 选择明确类型，保存类型身份 |
| 运动顺序 | `shot.camera_movement` 已要求有序列表 | 多段运动各自独立，不靠拼接字符串解释 |
| 起始位置 | 现有目录“起止位置” | 按同一参考坐标描述；技术键未定 |
| 结束位置 | 现有目录“起止位置” | 与起始位置使用一致参考；技术键未定 |
| 起始朝向 | 现有目录“起止朝向” | 描述开始时的朝向；技术键未定 |
| 结束朝向 | 现有目录“起止朝向” | 描述结束时的朝向；技术键未定 |
| 运动轨迹 | 现有目录“轨迹” | 归位移或组合运动，不归承托设备；技术键未定 |
| 运动时机 | 现有目录“时机” | 指镜头内部运动时机，不是制作排期；技术键未定 |

字段的专业含义、单位和适用类型需要在该字段自己的说明中维护。以后采用实拍空间、虚拟空间或画面参照时须明示参照，不能用相同数值冒充同一坐标。本轮只审阅归属，不确定新的默认坐标或数据模型。

## 4. 与其他小类的关联

| 本类需要的内容 | 所属小类/字段 | 使用方式 |
| --- | --- | --- |
| 实现运动的承托条件 | 摄影支撑；`cinematography.support` | 手持、稳定器、摇臂、轨道、无人机等作为实现条件，不当作纯轨迹类型 |
| 运动时的光学条件 | 镜头；`cinematography.focal_length_mm` | 引用焦段，不让焦距成为位移的子类型 |
| 跟随运动调整焦点 | 对焦；`cinematography.focus_distance_m` | 单独记录焦点目标或距离变化 |
| 画面取景范围 | 景别 | 景别下再放远景、中景等类型，不与运镜类型混排 |
| 运动在画面中的表达 | 构图、摄影角度 | 各自引用定义，不收进运动参数包 |
| 和人物行动配合 | 人物调度 | 关联行动时机，不把人物路线写成机位轨迹 |
| 连续性要求 | 动作轴线、180度规则 | 各自维护，作为相关条件引用 |
| 画面节奏 | 成片时长；`shot.duration_frames` | 只关联镜头内部节奏，不等于拍摄工时 |
| 推拉变焦 | 独立的复合镜头方法 | 分别引用摄影机位移和光学变焦，不混成单个物理参数 |

现有总纲的运动字段选项中还夹有支撑方式。此问题在本例里通过分类和关联明确区分；本轮不更改原枚举，待案例确认后再统一整理相关文档，不能把旧混合选项当作分类正确的证据。
