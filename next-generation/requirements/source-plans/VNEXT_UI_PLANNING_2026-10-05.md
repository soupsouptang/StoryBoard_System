## 3. 信息架构与页面清单

全站层负责项目入口、跨项目的我的工作、账号与管理员用户管理。项目内负责本项目的内容、人员、工作、排期、审阅和交付。知识入口根据权限查询公共基础知识与合格团队汇总，不把原始项目回答公开给团队。

建议把新增导航组织为可展开的“筹备与执行”组：场景、演职人员、任务、拍摄排期、通告、现场、时间段需求。首版不同时展开所有子项；打开后仍能直接定位正在使用的页面。现有分镜制作、制作分类、素材资产、审片版本、交付导出、制作概览和项目设置的名称及入口保持。

| 页面 | 当前依据 | 规划职责与候选路径 | 数据负责人 |
| --- | --- | --- | --- |
| 项目入口 | 已有界面，保留 | `/productions`，整行封面列表、搜索、新建、编辑入口 | 项目及封面引用 |
| 分镜制作及各视图 | 已有已明确界面 | 继续既有 `shots`、`storyboard`、`timeline`；只登记后端产生的缺口 | 镜头、面板、列、共享视图 |

## 4. 统一视觉与组件规则

新页沿用 New York 中性色、语义色令牌和已有 Satoshi／Sarasa 字体，不增加第三套字体或以工种颜色铺满背景。工种用文字与小标识，用户高亮色用于协作身份，不能混同任务阶段或权限。

桌面新页沿用已有 Shell：50px 顶栏、224px 展开导航、64px 收起导航。正文用 24px 外边距、16px 区块间距、8px 表单内部间距作为新页起点；现有已接受例外不改。按钮默认 36px，紧凑操作 32px；触屏新页扩展实际点击区域至至少 44×44 CSS 像素，不放大桌面已有控件。

列表优先弱分隔线、固定表头和清楚的行选择，避免每个单元格套卡片。概览只为有明确动作的摘要提供卡片；数字可点进同口径的明细，不放装饰性图表。预计与实际用不同文本和线型，不只靠颜色区分。

复杂对象用独立详情页；新页的快速查看可以用右侧 360—420px 检查区，编辑时保持上下文。普通筛选用 Popover，单项动作用 DropdownMenu，永久删除和发布影响用 Dialog。批量排期、通告编辑、导入映射用完整工作页，不套多层弹窗。这里的检查区不应用到已有镜头详情。

| 组件族 | 复用与补充边界 |
| --- | --- |
| Button、Card、Badge、Input、Textarea、Select、Checkbox | 已有 `@frameforge/ui` 导出；使用既有语义与尺寸 |
| Dialog、Popover、DropdownMenu、Tooltip | 已有共享实现；禁止每页新建一份焦点与遮罩逻辑 |
| Tabs、Slider、Calendar、Sheet、ContextMenu 等 | 当前共享导出未齐；列为待补组件，由共享 UI 负责人集中接入 |
| 表格、分页、筛选、虚拟列表 | 复用现有 TanStack 依赖；不同业务定义各自列与动作，不造万能业务表格 |
| 排期时间条、依赖连线、图片框选、二维／三维画布 | 是业务组合组件，shadcn 负责周围控件，不声称 shadcn 自带这些引擎 |
| 表单校验、拖动、裁剪、日期与时码 | 优先现有库和服务；新增依赖单独论证，日期时间和成片时码不混算 |

## 5. 项目入口：照片封面必须保留

保留每个项目一整行照片背景及渐变遮罩，标题和项目信息在左，更新时间、修改人、编辑与打开入口在右；不能替换为普通网格卡片、纯色图标列表、统计首页或平铺缩略图。当前最大内容宽度和对齐按已有项目大厅实现，不由本规划再次改版。

信息顺序遵循最新大厅记录：类型、画幅比例、帧率、镜头数量、总时码。时间显示项目时区并提供完整时间提示；空封面使用中性图案占位，项目仍可打开，不能自动拿无权素材补封面。

整行打开项目；编辑封面或标题按钮不触发打开。键盘可以聚焦项目入口及独立操作，封面本身不是唯一可访问名称。长标题截断但保留可读取全名；没有权限的管理入口不渲染，也由服务端再次校验。

未来手机仍是横向封面条目，右侧信息可转到条目下一行，不改成方形卡片。旋转和重排只影响个人显示，不保存为共享项目封面构图。

## 6. 岗位视图和一键操作

同一个人可有多个岗位。岗位切换只改变查询和展示，不授予项目权限，不复制镜头或任务。跨项目我的工作每条注明项目，受限项目只按当前授权显示。

岗位名称与分类读取工种目录：八个工种大类、全程／前期／特效／后期制作分工、实际部门、现实人员任职和账号权限分开。下表为工作视图示例，不是默认启用岗位清单；默认岗位选择暂缓，“添加岗位”授权角色与团队目录生命周期仍待该目录的后续确认，本规划不替用户决定或开发这些入口。

| 使用者 | 首页重点 | 一键入口与下一步 |
| --- | --- | --- |
| 导演／统筹 | 待创作确认、待审阅、补拍、计划差异 | 打开对应镜头或固定版本，确认后创建明确返工要求 |
| 制片／排期 | 待安排、人员与场地冲突、当天变化、未发布通告 | 生成当前拍摄日通告草稿；打开差异再发布 |
| 摄影／灯光／美术 | 本时段镜头、场景要求、布光、器材和道具清单 | 打开当前安排的镜头与需求来源，不进入库存流程 |
| 演员及其他现场人员 | 本人集合、妆发、待命、拍摄及释放 | 查看当前个人通告并确认所见修订；到场另外登记 |
| 素材管理／后期 | 待检查、缺素材、输入过期、待交接与返工 | 检查固定素材版本并提交交接，不以文件上传代替交接 |
| 项目管理者 | 未分派、失败联动、授权和交付风险 | 回到具体对象处理，不在看板直接跨模块覆写状态 |

“一键”指合理默认后少填重复信息，并不合并不同业务事实。自动生成草稿、显示个人今天任务、导出已保存模板可以单击完成；永久删除、切换当前方案、发布和对外分发需要展示具体影响。后台重复点击使用同一请求身份，不产生两张通告或两次交接。

## 7. 场景与演职人员

### 7.1 场景

左侧场景目录支持篇章、内外景、昼夜和待确认筛选；中部显示场景正文与关联镜头；详情分“内容、演员与准备、器材道具、安排与任务”四组。新建场景先填名称，其他未知信息可保存为待确认，不生成假地点和假时间。

场景关联镜头显示零到多个关系；设置主场景是独立动作。环境字段显示镜头明确值或主场景值，其他场景存在差异时给出原因和回查入口，不替镜头改变篇章。

要求每项显示来源、继承或手动覆盖。覆盖编辑支持增补、排除、替换、恢复继承；预览列出本次受影响的未覆盖镜头。场景删除预览关联，不连带删除镜头、人员或素材。

### 7.2 演职人员

人员目录与剧情角色分开页签，姓名相同仍是不同身份。详情分别展示登录账号关联、项目岗位、饰演角色、档期、任务和当日安排；手机号等个人信息按字段权限显示，不成为默认导出字段。

档期使用可用、暂定、不可用、未知四种状态，缺失不当作全天可用。一个人多个岗位只显示同一条人员时间线。跨项目共享身份只有显式关联后参与冲突检查；无权冲突只给授权摘要，不泄露其他项目标题、地点和联系人。

批量导入先预览同名候选，不能自动合并账号、角色和现实人员。任职管理与项目授权两个入口清楚分开，不能以设置“摄影”替代授权。

## 8. 任务、依赖和交接

列表默认显示标题、来源场景／镜头、主责、预计开始／结束、实际阶段、输入状态和下一动作。部门看板按真实阶段分列：待安排、可开始、进行中、待交接、已完成；阻塞、逾期、输入过期作为并存标记，不做互相覆盖的阶段列。

详情展示固定输入版本、主责与协作、前置任务、检查清单、固定输出、交接和操作历史。没有输入的任务解释缺哪一项；完成按钮实际提交产物，不能只把阶段改绿。独立审阅不允许执行者自确认，跳过展示管理权限、理由和下游输入检查。

应用模板打开实例化预览：创建、复用、依赖变化、缺配置分别计数；确认后同一来源幂等生成任务。共享场景准备只生成一项任务，多个镜头都回查这项事实。依总纲 D-35，只有系统生成、未开始、无实际记录、无产物、无交接的任务可自动标记不再需要／停用；人工任务和已经产生事实的任务保留并提示主责处理。停用不是删除或人工取消，恢复适用不复活旧执行事实。

检查区域分别展示必需／可选、待检查、已完成、不适用及来源失效，证据固定到定义版本。只检查是否具备或遗漏，不提供操作教程。可开始状态综合仍适用的任务、输入、必需检查和硬门槛授权资料；未知不是通过，可选未完成只提醒，允许的不适用需明确选择及理由。

拖动看板时先判断阶段转换条件，不能把已完成卡片拖入任意阶段来绕过交接。存在条件缺口时打开该卡的检查结果并保留原阶段。任务依赖图可辅助阅读，键盘列表也能完成相同编辑；连线不能创建循环依赖。

## 9. 排期、转场和现场

### 9.1 排期工作页

顶部是方案选择、摄制组、项目时区、拍摄日、保存状态、比较与当前方案标识。左侧待安排队列按场景、镜头或任务筛选；中部是拍摄日时间线；右侧是选中安排的详情、冲突和受影响对象。右侧只服务新增排期页。

拖入一个条目时先显示时间和依赖预览，释放后提交修订；相同镜头跨日安排不创建新镜头。拖动空闲时间不能改变片长。锁定项显示锁图标和文字，自动建议不解锁。未知时长以缺项显示，不画成零分钟。

方案比较并排显示拍摄天数、人员／场地冲突、转场、未安排工作、预计后期开始和来源修订，不给一个无法解释的综合得分。设为当前方案显示本次替换范围和通告草稿变化，原子切换，不能两套同时驱动同一摄制组。

### 9.2 转场

转场属于安排条目的类型。详情按撤收、装载、行驶、卸载、搭建分别记录时间，未知段单独提示；与相邻条目重复的搭建或撤收不能累计两次。地图估计如果未接服务就显示待填写，不假装已计算。

有先行组时显示独立安排及实际参与人员，不复制全体成员。地点变化或延误显示下一场最早开始和窗口冲突；用户可以查看建议顺序、另日安排或保留冲突，不自动取消镜头。

### 9.3 现场工作页

顶部突出项目日期、当前拍摄日、当前安排、预计收工和尚未解决的冲突。主列表分进行中、接下来、已发生三段。每项可以登记实际开始、实际结束、延误原因和更正；更正保留原事实和操作者。

镜头结果分别为已满足、部分满足、未满足或需要补拍，不能把“安排条目结束”当镜头完成。超时后显示哪些未来安排已重新预测、哪些被锁定、哪些需要处理；创作版本、旧通告和旧确认不被覆盖。

手机现场首要操作限制为当前安排、实际登记与回查；复杂批量重排回到完整工作页。网络断开时允许保留未提交输入，但明确显示未上报，不能在离线状态给其他人显示已开始。

## 10. 通告与时间段需求

通告列表按拍摄日显示草稿、最新发布修订、与当前方案差异、接收反馈和撤回状态；选择拍摄日后“一键生成草稿”从当前授权数据填入。通告编辑页是正文预览与来源检查，不另建一套可独立漂移的人员和排期。

个人集合时间、当天安排、地点、准备事项与联系人分别投影。发布、分发、送达、查看、确认、到场分开显示。依总纲 D-36，排期更新只刷新草稿、差异及需要重新确认的人；发布新修订和对外发送必须由有权限的人明确操作。允许发布后不发送，不提供由排期事件自动发布或自动外发的规则。

时间段需求页上方是时段／拍摄日／摄制组选择，下方按型号或道具汇总数量，展开可看到各场景、镜头及手动覆盖来源。独立需求相加，明确共用组只计一次；未排期和缺数量另列。没有库存可用、剩余或预留栏目，自有／租赁仅作需求备注。

## 11. 素材、画板和旁白

素材资产延用现有入口，筛选图片、视频、其他文件、未使用、待检查和有来源缺口。详情显示原图／原文件、版本、引用位置、默认构图、缩略图和处理状态，删除前列出受影响引用；永久删除有独立确认。

图片裁剪使用共用构图服务，内置 21:9、16:9、4:3、1:1、9:16 等常用比例及项目比例。保持原图和纵横比，缩放后黑填充，不拉伸。素材默认构图更新影响未设置专用构图的当前引用，镜头和封面专用构图保持；历史固定版本不漂移。图片在现有镜头两入口的控件、载入原图、锁定和保存行为不改。

素材交接工作区可沿用资产详情的附属入口：完整性、备份、代理和正式交接分别显示。固定版本输入过期时显示已交接版本与当前版本差异，不能偷偷用最新替换。依总纲 D-37，正式交接必须完整性通过且满足项目配置的备份验证；未满足时预览只能明确用于草稿预处理，不能变成正式输入可开始、正式审阅或交付依据。项目未配置的额外备份不作为隐藏门槛。

二维／三维灯光页复用同一画板场景，切换二维、分屏、三维只改个人观看状态；对象库、场景对象及属性分开。选中对象后才显示移动、旋转、灯光参数等适用控件。画布使用 Three.js 等现有库，不在文档阶段另写渲染器。画板保存及镜头关联要经过版本和租约校验。

情绪板保留图片、便签、色卡、链接和框选等基线能力，复用素材引用；可撤销重做但不进入项目创作版本。不能因没有创作版本把保存、权限或删除检查省略。

旁白页一条镜头一条文本与预计朗读时间，语速滑杆沿用已要求的 Codex 模型滑杆交互思路：拖动有当前档位、速度标签和可播放 TTS 样例。文字改动后标记需要重算，TTS 的声音、语言、样例时长和实际音频单独显示；预计计时不伪装成实测音频。生成异步，可取消、失败可重试，不打断正文编辑。

### 11.1 Excel、PDF、图片文字识别的导入工作区

沿用已明确的导入入口，不改分镜表格工具栏。新增或尚缺的导入步骤依次为来源选择、解析结果、字段映射、覆盖／添加影响预览、确认执行与结果。真实 XLSX 的工作表、表头、合并单元格和嵌入图片需要保留；PDF 原生文本与扫描页识别分开，图片文字识别显示页／区域及置信度。

映射按总纲数据字典的稳定字段键完成：原列名、原文、规范值、单位、来源位置和识别规则版本可回查。同义候选可建议但不得把低置信度当确认；非空意义冲突进入预览，不能自动覆盖。连续数值如 37.5mm 不被常用选项拒绝；“日光”没有明确数值时不直接写成 5600K。

列预览分已有内置、已有预设、已有自定义和拟新增列；初次打开九基础列规则保持，导入全部列不等于默认全部铺开。覆盖前固定目标修订、对象匹配和删除影响，执行时发生冲突回到预览，解析缓存仍可复用。每步可返回修正，确认写入后返回实际新增／覆盖／未处理对象及原因；取消预览不留下半个工程。

来源文件、图片和识别作业分别显示处理状态，不阻塞其他编辑。错误定位到具体工作表、页、行、字段；原文件和本地输入保留。识别／解析复用现有服务与成熟库，不由 UI 自建第二个解析器。

## 12. 版本、审阅、返工与交付

项目创作版本以提交列表、作者、时间、说明和差异摘要展示；选择两个版本可按镜头进入左右比较，增删用文字、图标及红绿提示共同表达。长段折叠未改部分，图片比较使用同一比例；不得改写已固定内容以迁就当前画面。

批注、审阅决定与创作提交分开页签和历史。解决一条批注不等于正式批准版本。需要修改的反馈明确生成或关联返工要求，回查源评论、固定输入、负责人、目标任务与补拍安排；同一来源重复点击不能建两份未完成返工。

交付导出同一入口区分“生成文件”和“正式交付”。下载文件不代表提交给客户；正式交付固定产物、允许字段、收件范围和验收记录。退回显示原因，并关联返工任务，历史验收仍属于旧版本。短期下载过期可重新生成，正式产物不被临时下载期限删除。

### 12.1 制作授权资料与最终检查

资料工作区按人物肖像、地点、音乐、素材、字体、标识和航拍许可等制作类型筛选，显示固定文件版本、适用对象、范围、期限和来源。记录已过期可以由明确日期判断，但不能显示系统作出的法律有效结论。一个记录可关联多个对象，不作为镜头的一列文件名。

只有项目明确配置为硬门槛的必需授权参与可开始／最终检查；缺失、过期、未知、不适用和可选提醒分开。文件存在不等于全部用途获准，允许的不适用需要明确权限和理由。授权变化重算未来检查，不改写已经拍摄、发布或交付的事实。此功能只管理资料，不扩展费用、合同或法律判断。

## 13. 知识、设置和管理

知识页分“型号与基础知识、项目经验、统计、候选建议”。型号页有资料来源、单位、适用条件和核验状态，不加入设备使用方法或仓储字段。项目经验原始回答按项目权限隔离；团队只能看满足样本条件的去标识汇总。

经验问答在收工或阶段结束非阻断提示，每个账号跨项目每天最多三个主题；可以稍后。候选校准显示样本数、适用条件、依据、改变哪些未来预计或流程，并由明确确认命令接受。AI 提案必须独立材料与人工核验后才入正式知识，不能因界面标签“可信”直接写业务数据。

项目设置继续独立页面，保留标题、画幅、帧率、分享状态、项目授权和偏好等明确内容。改画幅预览受影响图框；改帧率保留秒数重新计算帧数与时码，音频及拍摄实际时间不被改变。个人时区只改显示，项目默认变化先预览。

用户管理只在管理员授权下可见，账号、用户组、团队归类、用户颜色和账号状态分区。岗位名称不授予管理员权。新经验贡献到采集时项目成员所属全部团队，历史贡献范围不随换组改变；管理页解释此规则，不能把换组包装成撤回全部旧经验。

## 14. 右键、键盘与选择

| 上下文 | 适用动作 | 禁止的混用 |
| --- | --- | --- |
| 既有镜头行／列 | 完全遵循最新列与菜单记录，复制、剪切、按既定方向粘贴 | 不恢复独立 duplicate、旧双向粘贴和已去掉的归档 |
| 新场景行 | 打开、关联镜头、查看要求、添加任务、删除及恢复 | 不因删除场景连带删除镜头 |
| 任务卡 | 打开、分派、查看依赖、提交交接、按条件取消 | 不用拖动绕过阶段转换条件 |
| 排期条目 | 打开详情、锁定／解锁、查看冲突、移出方案 | 移出安排不是删除场景／镜头 |
| 素材 | 查看来源／引用、默认构图、下载授权版本、删除 | 不以共享素材裁剪覆盖专用构图 |
| 灯光对象／情绪板选中项 | 只展示对应对象的适用修改和删除 | 空白画布菜单不能显示对象动作 |
| 通告修订 | 查看、与前版比较、生成授权副本、按权限撤回 | 已发布正文不能原地修改 |

右键功能必须有按钮或菜单替代，触屏长按与更多按钮可达；不要求触屏先模拟右键。输入框的 Ctrl/Cmd+C/X/V 保持原生文本操作，页面选择快捷键不吞掉中文输入法、文本选择与已有图片历史快捷键。

新页多选显示真实数量；批量操作先展示受影响身份和例外，不能仅操作当前加载页却声称全部。焦点关闭浮层后回到触发项，Esc 取消浮层内未提交动作，失败输入保留。

## 15. 动画设计

对新页采用以下建议参数，复用现有动效实现和主题变量；不回头修改已接受控件。能表达选择、移动、展开、处理和因果的交互都设计动画，不增加产品 Reduced Motion 开关。

| 情境 | 动画提案 | 完成与中断要求 |
| --- | --- | --- |
| 按钮、行悬停和选择 | 100—140ms 背景／边框过渡 | 不抖动文字和列宽，离开即时反向 |
| Popover、菜单 | 140—180ms 淡入与 2—4px 位移 | 不从屏幕另一侧飞入，反复打开不累积 |
| 新页侧边检查区 | 180—220ms 轻位移 | 内容焦点及时可用，取消不提交 |
| 展开来源、未改差异 | 160—220ms 高度过渡 | 可打断，大列表不为全部行同时计算 |
| 拖动与重排 | 120—180ms 邻项让位，插入线同步 | 保存失败回到权威位置，保留拖动目标供重试 |
| 排期影响 | 200—260ms 旧／新位置提示 | 先标明建议或已应用，锁定条不移动 |
| 异步处理 | 有进度时进度条；未知时轻量活动标识 | 不伪造百分比，不无限闪烁已完成项 |
| 完成与错误 | 一次状态过渡并保留文字结果 | 成功不是只播动画，错误不自动消失 |
| 画布工具 | 选框、抓手、对齐线随输入即时反馈 | 不给实际拖拽增加缓动延迟，复杂三维不阻塞表单 |

不使用抢占编辑的全屏庆祝、持续脉冲、自动横向滚动标题或后台每次刷新都播入场。打印和导出是静态结果，动画状态不进入导出。

## 16. 异步、协作与错误反馈

保存状态分未保存、正在保存、服务器已保存、冲突和失败。已明确镜头详情的绿色已保存表现保持；新页借用语义但不全局替换现有样式。最近更新时间来自服务端，刷新完成说明同步到哪个修订；不把请求发出时间当保存时间。

适合先改后上传的低风险编辑保留本地草稿，收到确认才固定。发布、永久删除、当前方案切换和交接使用明确服务端命令；失败不显示假成功。读取和可重建缩略图可以缓存，缓存按项目授权和修订区分，撤销权限后清除可见内容。

多人编辑先取得相应范围的编辑租约，再修改。光标、选区及当前表单框显示人员颜色与名字，不进创作版本；颜色相近时仍能靠文字区分。租约过期或被别人持有显示查看模式和重试入口，不自动抢锁。

冲突页显示你的草稿、服务器值、变更时间和可处理项；不能自动用最后一次请求覆盖对方。共享视图的列显示、顺序、宽度、行高、筛选、排序和分组实时同步；选择、光标、草稿、手机展开状态与个人画布视角独立。

错误文案说明“什么没完成、输入是否保留、下一步在哪里”，例如“时间安排已保存，通告草稿更新失败，可在变化记录中重试”。影响联动失败不回滚已经保存的源事实，不能给含糊的“整个操作失败”。内部日志编号可展开复制，不直接展示堆栈、数据库字段或敏感地址。

## 17. 多端适配提案

以下宽度仅用于未来新页容器规划，不是本轮验收或改动现有 UI 的指令。按容器空间与输入能力响应，不按设备名字推断权限。

| 容器和输入 | 首要工作 | 结构调整 |
| --- | --- | --- |
| 桌面约 1280px 以上，指针 | 筹备、批量编辑、完整排期与比较 | 保留多区布局；检查区可收起；表格局部横向滚动 |
| 中等约 768—1279px／触屏平板 | 当天计划、画板、审阅与局部编辑 | 待安排和检查区一次打开一个；时间线保留时间刻度，不缩成不可点的截图 |
| 小容器约 767px 以下／手机 | 本人通告、当前任务、现场登记、查看和确认 | 单列摘要→独立详情；保留返回上下文；主动作不被键盘遮挡 |

复杂操作在手机可进入分步骤详情，不用“手机版”复制数据库或改共享列宽。表格的共享筛选与列设置不因手机折叠而改变；个人摘要仅是同一查询的展示。屏幕旋转保留对象、草稿和滚动位置，不能触发业务保存。

正式通告提供按人优化的 HTML 阅读页和纸张 PDF 两种结果，原发布身份不变。未知网络能力不默认提供离线可用承诺；只缓存授权读取和未上报草稿，发布及确认必须取得服务器回执。

## 18. 实施路线与完成标准

本次不启动以下实现。编码时分包，不把导航、排期、媒体和通告写在一个大模块里；服务和共享组件分别由原负责人修改。现有机器清单需要由协调者添加对应包后才能宣称已排入执行。

| 阶段 | 独立交付 | 前置条件 | 验收要点 |
| --- | --- | --- | --- |
| P0 归属核查 | 当前路由／组件／接口地图、受保护 UI 清单 | 最新 Git 和需求核对 | 不创建重复页，不覆盖并行草稿 |
| P1 基础组合 | 新页缺失的共享组件、表单状态和查询骨架 | `packages/ui` 负责人接入 | 键盘、焦点、失败保留和桌面截图 |
| P2 内容与人员 | 场景、出演、任职、档期，各自独立包 | 实际业务 owner、权限和命令 | 多场景覆盖、同名不合并、未知档期 |
| P3 任务 | 模板实例化、我的工作、依赖、交接分别交付 | 固定输入输出、阶段规则 | 幂等、循环依赖、独立审阅、输入过期 |
| P4 排期与需求 | 方案、转场、时段汇总、冲突回查 | 任务与人员查询 | 多方案只一个当前、锁定、未知不作零、共用去重 |
| P5 通告 | 草稿、发布、授权个人页、反馈 | 当前方案与字段投影 | 不可变修订、个人时间、旧确认保持 |
| P6 现场与媒体 | 实际登记、重排影响、素材交接 | 实际事实和素材版本 | 超时不删镜头、缺项不假交接 |
| P7 审阅与交付 | 差异、返工、补拍与正式交付回流 | 固定版本和任务关系 | 评论不代替批准、旧验收不覆盖 |
| P8 知识与校准 | 非阻断问答、团队汇总、候选建议 | 来源与固定贡献范围 | 样本不足不出结论、接受只改未来 |
| P9 多端 | 新页的平板／手机展示和操作验收 | 桌面先通过 | 同一事实、共享视图不漂移、触屏动作可达 |

每包先证明真实业务流，再检查空、加载、无权限、失败、冲突、多人修改、删除和恢复状态。桌面证据先保存 1440×900 与 1920×1080 正常缩放的实际运行截图；规划图和源码截图不能替代。未来多端另设包，不能用测试范围扩张阻塞当前已明确桌面。

最终闭环至少使用合成项目走通：多场景镜头→任务和主责→档期与排期→转场→通告固定修订→实际超时→未来影响→固定素材交接→后期产物→审阅返工或补拍→正式交付→经验候选校准。每一步可回查来源及失败边界，不能以所有菜单都能点击代替。

## 19. 数据字典如何落到控件与看板

总纲 3.3 第20节是字段语义来源。页面不一次展示两百个字段，不为不同工种新建同义数据；基础表格保持九列，更多专业字段进入有权的详情组、预设列、自定义列与导出模板。

| 字段类别 | 新页控件和显示 | 保存与回查要求 |
| --- | --- | --- |
| 稳定分类 | 有本地化标签的 Select，允许扩展的分类提供明确项目字典入口 | 稳定代码，未知代码不能悄悄存自由文本 |
| 型号等字典引用 | 可搜索 Combobox，查看基础资料与来源；同名显示可辨身份 | 固定字典身份与当时标签，不用型号推定实际参数 |
| 连续数值 | 数值输入＋单位，常用值为快速选项，例如焦段 37.5mm 可输入 | 规范数值和单位，真实零不是空值 |
| 自由说明 | 文本／长文本，标明不参与严格计算 | 不从描述猜实际时间、数量或权限 |
| 未填写／未知／不适用 | 文字状态可明确选择，原因按定义显示 | 与 0、false 分开，导入导出同样保留 |
| 预计／计划／基线／预测／实际 | 明确标签与对比列，实际更正显示历史 | 时区、帧率、来源修订和事实类型固定；不能互相覆盖 |

摄影页分机身／镜头型号、计划参数、现场实际；灯光页分需求、准备确认、实际使用；后期详情分固定输入、制作技术参数、产物和审阅状态。工作分辨率与交付分辨率、采集帧率与时间线帧率、源时码与时间线时码分别显示。选择镜头型号不会自动写入焦段，选择工种不生成任职或权限。

看板指标必须有统计对象、分子／分母、排除项、去重键、时间范围、权限、来源修订和计算版本。点击数值下钻到同口径对象；未知单列，不从总数剔除后假装全部完成。制作效率不能按人员姓名排名，知识校准只能读取明确实际和合格汇总。

上传前机器清单已从33包增到38包，包含 E2-AUTHORIZATION、E4-CHECKLIST、E6-MEDIA-HANDOFF、E7-DELIVERY-LOOP 和 Z0-PRODUCTION-CLOSED-LOOP；业务 gate 已扩至 FX-32。上面 P0—P9 是界面实施顺序，不是替换现有包身份或凭文档提升状态。新增页分配到既有 E9／K5 及相应业务包，由协调者登记消费者和可改路径。
