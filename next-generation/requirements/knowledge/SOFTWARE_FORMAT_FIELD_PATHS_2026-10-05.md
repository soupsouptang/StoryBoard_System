# 软件资料和格式资料的字段路径

日期：2026-10-05。下一代规划，尚未实施。这里定义共同字段阅读方式，不建立与 A–H 并列的软件部门或格式部门，不填写实际软件能力值。

入口由[知识总目录](../KNOWLEDGE_CATALOG_STRUCTURE_2026-10-05.md)所属工种和专业小类提供。软件与格式保持独立身份，通过具名支持关系连接；技术键尚未确定的描述项仍是设计提案。

## 1. 软件资料

路径：工种大类 → 专业小类 → 本能力所用软件的厂商 → 产品 → 适用版本 → 能力项 → 方向 → 条件和字段。不同工种引用同一产品资料，不复制产品或其能力正文。

| 资料分项 | 独立字段 | 用途和边界 |
| --- | --- | --- |
| 产品身份 | 厂商、产品、中英文名称、产品代码 | 四项分别保存，别名不生成第二份产品身份 |
| 适用版本 | 产品版本、平台、地区、官方限定 | 各条件独立；未指定版本不等于全部版本支持 |
| 能力项 | 能力身份、中文名称、输入要求、输出要求 | 产品分类不代表所有能力都成立 |
| 支持关系 | 格式引用、方向、支持等级、限制、必要组件 | 产生、消费、导入、导出、转码分别记录，不能互相推出 |
| 证据 | 来源位置、修订、核验状态 | 逐能力绑定，不把产品首页当作全部能力证据 |

每一字段在适用能力的专业小类内关联岗位。例：F 类实际二维合成能力关联 F 类承担合成的既有岗位；G 类预演能力关联既有预演岗位；H 类输出能力关联既有交付岗位。具体岗位身份从[岗位知识绑定](../ROLE_KNOWLEDGE_CATALOG_2026-10-05.md)的专业域取得，参见各分册逐字段表，不依软件名称推测岗位或授权。

## 2. 格式资料

路径：工种大类 → 专业小类 → 格式类别 → 格式身份 → 结构或配置版本 → 参数。格式本身只有一份定义；软件、摄影机等产品各自记录对这份定义的支持。

| 格式类别 | 本类继续展开的字段 | 不混入的内容 |
| --- | --- | --- |
| 容器 | 封装身份、结构版本、允许的编码引用、轨道结构 | 不由文件扩展名推定编码 |
| 视频编码 | 编码身份、配置、级别、位深、采样、尺寸或速率条件 | 容器名称不能替代编码参数 |
| 摄影原始格式 | 格式身份、记录配置、解析条件、版本、元数据结构 | 不复制设备型号或把格式当成可装配器材 |
| 图像格式 | 静帧或序列、通道、位深、压缩、色彩解释、元数据 | 序列帧数不是知识库里的项目事实 |
| 音频格式 | 编码、采样率、位深、声道、封装关系 | 时间码和参考同步另引用对应知识 |
| 字幕格式 | 结构版本、时间表示、文字编码、样式支持、限制 | 不把字幕文字保存成格式属性 |
| 工程交换格式 | 结构版本、可表达对象、必需字段、引用方式、限制 | 交换结构定义不等于某软件完整导入成功 |

各类别最少有中文名称、英文检索名、别名、格式身份、规范来源和修订。参数带单位、范围和适用条件；不适用、不支持和未知分别保存。产生/消费/导入/导出/转码属于产品支持关系，不属于格式自身的一条无条件能力。

## 3. 字段与岗位关联

这里展开共同字段的具体读取目的。岗位绑定仍由专业域维护，表中岗位都是既有身份，不新增任职或写权限。

| 字段 | 相关岗位 | 适用条件和用途 |
| --- | --- | --- |
| 产品身份各字段 | 对应专业能力的既有岗位 | 核对自己使用的产品，避免同名或版本资料混用 |
| 产品版本 | 对应专业能力的既有岗位 | 读取能力实际适用的版本范围 |
| 平台 | 对应专业能力的既有岗位 | 存在平台差异时核对，不默认所有平台同能力 |
| 地区 | 对应专业能力的既有岗位 | 官方资料确有限定时使用，缺值保留未知 |
| 官方限定 | 对应专业能力的既有岗位 | 阅读该能力明确的模式、组件或其他条件 |
| 能力身份 | 对应专业域的既有岗位 | 回查唯一能力定义，不用产品名代替能力 |
| 能力中文名称 | 对应专业域的既有岗位 | 明确该项工作的内容 |
| 输入要求 | F10 合成师；H01 剪辑师 | 仅在本岗位消费该产品能力的输入时读取；岗位映射以工种表为准 |
| 输出要求 | D14 DIT／数字影像技术员；H18 输出交付／版本管理 | 仅在该能力产生或交换正式数据时读取 |
| 格式引用 | D14 DIT／数字影像技术员；H02 剪辑助理；H18 输出交付／版本管理 | 核对输入输出或交换格式的身份，不推定当前软件支持 |
| 方向 | 对应输入或输出岗位 | 分别读取本次产生、消费、导入、导出或转换方向 |
| 支持等级 | 对应专业域的既有岗位 | 判定该版本和条件下的能力，缺证据不当成不支持 |
| 限制 | 对应专业域的既有岗位 | 核对功能子集、模式和配置限制 |
| 必要组件 | 对应专业域的既有岗位 | 核对组件依赖，仅是资料条件，不自动安装或采购 |
| 容器各参数 | D14 DIT／数字影像技术员；H02 剪辑助理；H18 输出交付／版本管理 | 处理素材封装或交付封装时分别读取 |
| 视频编码各参数 | D14 DIT／数字影像技术员；H01 剪辑师；H18 输出交付／版本管理 | 核对编解码和记录、输出的明确条件 |
| 原始格式各参数 | D14 DIT／数字影像技术员；H02 剪辑助理 | 接收、解析或交接原始素材时读取 |
| 图像格式各参数 | 对应二维、三维、调色专业域的既有岗位 | 本能力使用静帧或序列时关联；通道或色彩需求不普遍绑定全部岗位 |
| 音频格式各参数 | D12 现场录音师；H07 对白剪辑／降噪修复；H13 混音师 | 按本岗位实际录制或消费音频的范围读取 |
| 字幕格式各参数 | H14 字幕制作／字幕校对 | 本能力使用字幕结构时关联，角色名从岗位表读取 |
| 工程交换格式各参数 | 对应专业交换能力的既有岗位 | 核对交换中实际表达的对象，不以格式存在宣称互通 |
| 来源位置 | 对应字段的专业消费者 | 回查支持断言的具体位置 |
| 修订 | 对应字段的专业消费者 | 固定使用的定义和支持记录修订 |
| 核验状态 | 对应字段的专业消费者 | 区分已有证据、部分证据、冲突和未知 |

表中按类别展开的参数各自有一行规格定义和岗位关联，不在运行数据中保存成一项大字符串。专业域名或岗位显示名有误时只修显示名，不能变更稳定岗位身份。
