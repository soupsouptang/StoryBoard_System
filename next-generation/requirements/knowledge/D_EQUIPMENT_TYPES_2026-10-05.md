# D 类器材：对应项、预设类型和专属字段

版本：1.0，2026-10-05。下一代设计提案，尚未实施。这里只补分类结构、初始类型、字段路径和自定义方式；不改变现有型号参数，不填实际产品、数值、接口配对或新的官方核验结果。

入口：[D类知识分册](D_KNOWLEDGE_HIERARCHY_2026-10-05.md)、[器材字段分册](D_EQUIPMENT_FIELDS_2026-10-05.md)、[类型维护合同](../KNOWLEDGE_TYPE_OPTIONS_AND_CUSTOM_2026-10-05.md)。类型是在所属小类内展开的知识内容，不是与A–H并列的新库。

## 1. 阅读和保存规则

先读器材小类，再区分它的真实类型、独立分类维度和资料分项，最后展开共同字段及适用的专属字段。每个型号只有一份身份；跨摄影、灯光等用途通过关系引用。数值、接口、使用用途、商品品牌和兼容结论不能混成一套类型。

预设是初始可选范围，允许按[统一维护合同](../KNOWLEDGE_TYPE_OPTIONS_AND_CUSTOM_2026-10-05.md)登记自定义类型、维度值或型号；不得添加虚假的设备模式、官方型号、受控结果或支持能力。自定义项继承适用字段，专属字段带定义、单位、来源及岗位。

本篇的分类选择采用统一字段服务的字典身份及修订。已有类型键例如 `modifier_type`、`support_type`、`form_factor`、`effect_type` 继续使用；没有键的分类维度先登记字段定义再实现，不自动新增数据库列。字段定义权威入口仍是器材字段合同，岗位权威入口仍是工种与专业域映射。

| 已有字段 | 展开方式 | 专业用途 |

| `modifier_type`：附件类型 | 指向明确叶类型；祖先路径读取同一类型关系，不另存冲突名称 | 按实际结构检索预设/自定义，并选择相应字段模板 |

| `dimensions_mm`：尺寸 | 按对象拆长、宽、高；直径、罩深、出光口尺寸是各自定义的量，不强塞同一个三维向量 | 核对出光面、结构空间和安装条件 |

| `host_support_links`：灯具支持 | 只在灯具确为宿主时引用灯具；宿主是另一附件或独立承载时使用安装细则的具名支持关系，不扩大本字段语义 | 格栅可支持某柔光箱，不应绕过它直接宣称支持全部灯具 |

## 3. 机械组件的独立类型

支架、怪手、夹具和安装座在摄影支撑与灯光支撑入口可被引用，但每个实际产品只有一份型号资料。这里按结构细分；真实承载与连接仍按[安装细则](../EQUIPMENT_SUPPORT_DETAILS_2026-10-05.md#33-支架)及[怪手结构](../EQUIPMENT_SUPPORT_DETAILS_2026-10-05.md#34-魔术手臂怪手)逐端核对。

| 对应项 | 初始结构类型 | 继续展开的字段 |
| --- | --- | --- |
| 支架 | 固定支架、俯仰支架、多轴调节支架 | 支撑端、承载端、调节轴、各轴范围、防转、锁紧、空间及姿态载荷 |
| 魔术手臂（怪手） | 单关节结构、多关节结构、联动锁紧结构 | 两端、各关节、轴、调节范围、锁紧关联及伸展姿态；关节数量与联动锁紧分维度 |
| 夹具 | 平面夹持、杆件夹持、明确专用夹持 | 夹持对象、范围、接触面、夹紧/防滑条件、另一端安装点 |
| 安装座 | 固定安装、滑入安装、快拆安装 | 本体位置、接收/插入结构、定位、防转、防脱及对应支持 |
| 销孔连接件 | 插入销、接收孔、双端连接件 | 两端尺寸、方向、止挡、锁定、工作方向及明确来源 |

螺纹制式、内外螺纹、完整代号、长度、牙型和啮合条件不是这些器材的“子型号”。机械、视频、供电和控制连接逐功能判定，实际组合只写在真实资料或项目配置。

## 4. 完整性和后续验收

本篇覆盖字段合同已有第4.1—4.27节的全部27个资料小类；第4.28结构值及第4.29安装校验属于共同保存/判断合同，不伪装成两种器材。新增控光专属定义是提案，其余型号参数不改。

| 核对项 | 后续真实验收 |
| --- | --- | --- |
| 控光对应项 | 类型选择、字段适用、中文检索和自定义均可回读；标准罩/深抛/菲涅耳不是悬空名词 |
| 多维结构 | 同一镜头或灯具多维分类可共存；不预造类型排列，不重复型号身份 |
| 附件宿主 | 支持宿主是灯具、另一附件或独立承载时路径明确；概念关系不得用作兼容证据 |

| 未知资料 | 空模式、空宿主、未知载荷保持未知，不被预设或自定义绕过 |
| 原资料 | 保持原型号值和核验状态；新字段缺值必须在真实资料补证，不冒充官方验收 |
