# 下一代技术接受要求

状态：规划储备，未开始实现。本文将有效技术合同从旧代码适配方案中分离；不锁定旧路径、接口、迁移父节点或测试名。对应[总纲](VNEXT_MAX_EXTENSIBILITY_REQUIREMENTS.md)、[验收场景](ACCEPTANCE_SCENARIOS.md)及[导出设计](../EXPORT_DESIGN.md)。

## 命令、回执与保存

每条命令包括项目/对象身份、操作类型、预期修订、幂等键及规范化请求。身份来自服务器认证，不能信任客户端自报权限。相同键和请求重试返回同一回执，不同请求复用键拒绝。无变化不更新修订、更新时间、审计、历史或事务事件。

服务器在同一数据库事务完成业务写入、幂等回执、适用历史与待发布事件后才确认保存。并发校验失败返回明确冲突并保留草稿，不能最后写入覆盖。导入和批量命令使用同一业务规则；批量原子或逐项执行需在预览和回执明确，不能把部分成功报成全部完成。

错误输出有可供程序识别的代码、用户能理解的说明、受权对象范围和重试办法；日志保留技术原因但不返回凭据、私人正文或堆栈。字段级错误能定位具体输入。权限撤销同时影响查询、计数、历史、媒体、导出、实时连接及缓存。

## 历史与删除

新版唯一命令历史服务管理可撤销动作。每个用户、每个项目最近一百步，复合动作一条，失败不移动游标；表单原生撤销与项目撤销分开。撤销也校验权限、当前修订及来源，不能覆盖他人的后来编辑。

创作提交固定场景、镜头、有效图片构图和灯光内容，提供项目级及镜头级比较。人员隐私、授权、任务执行、交接、通告、批注、审阅各自历史。共享视图和情绪板不进创作提交；情绪板可撤销。发布和执行事实通过更正、撤回或新修订处理，不用普通撤销抹去。

普通删除可同身份恢复；永久删除需预览与确认，清受控当前值和历史正文，仅留无正文内部标记。内置列不可永久删除，预设、自定义列可永久删除。清理涵盖所有用户撤销、索引、缓存、来源、作业暂存和受控下载；共享原图按有效引用保护。备份恢复先应用删除标记，防止被清内容复活。

## 作业、事件、媒体

作业、事件发布、存储采用成熟第三方设施，通过单一适配器消费。本代重新建立持久任务和事务事件，禁止直接搬用旧服务。重复、乱序及失败可追溯、重试；跨域消费者失败不回滚已确认源事实。发布前重验来源修订、权限和删除标记，取消和迟到结果不得进入当前数据。

原图不可变，缩略图异步生成；默认构图只影响未设专用构图的当前引用，专用构图保留。历史、审阅及导出固定图片版本和有效构图。图片不拉伸，按21:9、16:9、竖版等选择适配并黑填充。素材库与镜头引用共用同一构图服务。

## 导入与导出

Excel、PDF、OCR等由统一解析管线接成熟库，保留文件身份、修订、原行页、源列、嵌图和置信状态。识别后提供覆盖、添加与完整预览，用户明确确认后才发业务命令；不建立客户长期导入模板。重复确认不重复写，来源或目标变化需新预览。独立对象关系和未知列不能凭同名自动绑定。

导出先生成同一授权字段投影，再由各格式渲染；正文、隐藏工程数据、附件、图片及便携包均不得漏出排除字段。PDF、Word、剧本、分镜表、通告、工程文件分别做回读和排版验收，长文不截断，横竖纸张与横竖图框独立。

工程QR/DM采用版本化协议、分片顺序、包身份、分片及整包完整性校验。必须从实际渲染页面像素解码，测试乱序、重复、缺码、混包、未知格式与超容量。只有码而无媒体字节时返回缺失媒体清单，不假称完整恢复。纯数据工程格式和附件包都走同一受权投影及导入预览。

**隐写追溯单独验收**：二维码/DM、普通hash、文件metadata均不能替代。选成熟库后先测固定种子合成图：原图、四边各裁10%、保留中心70%、1440桌面截图、截图后 JPEG quality80、缩放0.75。每类30个不同 payload＋30个无水印控制；记录成功恢复率/误识别率及不可恢复类型。上述每类30个样本是算法筛查门槛：至少27/30正确恢复、控制0/30误识别，仅用于决定能否进入完整验收。最终接受按功能计划的更严格门槛：每类100个不同追溯标识及100个无水印对照，恢复率至少95%、对照零误识别，包含保留50%面积的裁剪及实际截图链。筛查通过不能降低最终标准；两者都是待运行目标，不提前声称已达到。达不到时保留 BLOCKED，不写免责标注掩盖失败。PDF/Word 中嵌入图与 raster页、工程纯文本 metadata 的可追溯方式分别标明；不能用图片算法承诺纯文本抗截图能力。

## 新数据库和真实验收

从空PostgreSQL建立独立Alembic链，不继承旧数据库、旧迁移、旧媒体或配置。集成者串行合入结构变更；后续新版升级不修改已发布迁移，有新数据时前向修复。真实数据库验证外键、同项目关系、唯一约束、幂等竞态、事务回滚、锁序与删除防复活；SQLite不能代替。

实施时记录提交、测试命令、断言、退出码、合成/获准脱敏证据与未通过项。浏览器检查覆盖桌面、平板、手机、正常缩放、输入法、键盘、触屏、冲突和异步反馈；PDF逐页渲染并回读中文。文档、示意图或构建通过不代表功能完成。
