# D 类器材：配件、附件、接口及安装支持字段

版本：1.0，2026-10-05。用户已要求细化配件、附件、接口、摄影机监视器、支架及怪手的安装差异。本篇是下一代字段设计，尚未实施；技术键为设计提案，不表示型号已有这些参数。

大类为 D「实拍：摄影、灯光、录音与现场」。从[知识总目录](KNOWLEDGE_CATALOG_STRUCTURE_2026-10-05.md)进入各器材小类；既有参数键以[器材字段合同](EQUIPMENT_REFERENCE_FIELD_CONTRACT_2026-10-05.md)为准。本篇只展开这些键内部的对象、端点、条件和判断，不另建一套同义参数。真实厂商、型号、规格值及直接安装配对只放[真实数据样例](REFERENCE_SEED_DATA_2026-10-05.md)，本轮不重新查证或修改相机参数。

## 1. 先分器材身份，再看这次怎样使用

“摄影机支持附件”是该摄影机资料中的支持入口，不是把所有附件归摄影机所有。“机上监视器”描述用途和安装位置；它仍是监看设备，可以在别的有效安装条件下作独立监看。内置屏幕属于机身的真实组成部分，不能与外接监视器混成一个字段。

| 器材小类 | 下级类型或资料分项 | 本类维护的内容 | 从其他类读取的内容 |
| --- | --- | --- | --- |
| 摄影机 | 机身；真实内置成像模组；内置显示；机身安装点；机身端口 | 机身拥有的孔、座、卡口、端口和内置组件 | 外接镜头、监视器、支撑、供电的明确支持关系 |
| 监看设备 | 监视器；具录制功能的监视器；其他既有监看类型 | 自身安装点、输入输出、显示、录制、控制和电源能力 | 机上、桌面或其他用途成立的条件；用途不生成第二份型号 |
| 摄影支撑 | 底座；支架；夹具；魔术手臂（怪手）；监视器支架 | 自身支撑端、承载端、关节、锁紧和承载条件 | 指定设备或安装点的支持证据 |
| 快拆组件 | 快拆板；接收座；锁扣等真实组件 | 各自接口、方向和锁定条件 | 已明确的系统、板和座的组合关系 |
| 镜头连接环 | 螺纹连接环；夹持连接环等实际类型 | 两端规格及有效安装尺寸 | 所需镜头前端、滤镜或承载件条件 |
| 光学附件 | 专用增广附件等实际类型 | 光学作用、宿主范围、自身安装条件 | 明确宿主、变体、模组及模式；不按“也是镜头”扩散 |
| 滤镜 | 圆形滤镜；片式滤镜等实际类型 | 外形、尺寸、厚度和安装要求 | 承载系统支持关系 |
| 遮光斗 | 安装分项；承载分项 | 镜头连接、导管支撑、滤镜架或托盘连接条件 | 指定连接环、滤镜承载件和支撑条件 |
| 滤镜架 | 槽位；锁定件等真实组成 | 片幅、片厚、槽位和托盘支持 | 滤镜、托盘、遮光斗的具体条件 |
| 灯具 | 控光连接；支撑连接；供电；控制 | 每类接口及安装点分别记录 | 控光附件、支撑、供电和控制设备的支持 |
| 灯光支撑 | 灯架；夹持件等实际类型 | 承载端、底座和支撑限制 | 灯具、灯头附件和固定条件 |
| 线缆 | 每个插头端；内部功能 | 端头、线序、方向及实际传输功能 | 连接设备的端口模式、供电及协商条件 |
| 转接件 | 输入端；输出端；供电端等实际端点 | 被动连接或主动转换的明确能力 | 每侧设备和模式条件 |

上述类型是知识细分，不为每个名词新建一级业务对象。型号、变体等身份沿用已有基础合同；安装点和端口是某型号、变体或真实组件拥有的从属资料。独立器材之间的安装、随附、推荐和功能支持使用具名关系。一个实物同时承担支架和供电等作用时，仍保持一份型号身份，分别展开能力。

## 2. 支持入口必须继续展开到具体对象

每个型号有安装点清单和端口清单，而不是一个笼统的 `接口`。同一标准可在同一机身上出现多次，每个位置有独立身份。多个真实孔位组成一个防扭安装阵列时，保留成员孔位，另记录阵列要求；不能把一个阵列当成单个螺孔。

### 2.1 安装点

| 中文字段 | 提案键 | 内容及适用条件 |
| --- | --- | --- |
| 安装点身份 | `mount_point_id` | 在所属型号或真实组件内稳定；型号相同不表示各位置可互换 |
| 所属器材路径 | `owner_path` | D → 器材小类 → 品牌 → 型号 → 变体/真实组件；引用既有身份和修订 |
| 安装点名称 | `label_zh` | 中文位置名称，不只写“螺口” |
| 安装位置 | `location` | 顶部、底部、侧面等位置；有资料时附局部坐标、单位和坐标系 |
| 安装类型 | `mount_kind` | 螺纹、卡口、插座、导管、夹持、滑轨、快拆、磁吸或专用锁扣；具体类型必须再展开 |
| 接口规格 | `interface_definition_ref` | 精确标准及版本；标准本身有独立定义，位置只引用它 |
| 端点形态 | `endpoint_form` | 外螺纹/内螺纹、插头/插座、板/座、夹具/被夹持件等，按类型选用 |
| 几何条件 | `geometry` | 尺寸、允许插入或夹持范围、孔位阵列；按第3节结构保存 |
| 安装方向 | `orientation` | 允许朝向、插入方向、装配姿态；资料缺失时未知 |
| 连接方法 | `fastening` | 旋紧、夹紧、卡扣等连接方法；锁紧机构单独说明 |
| 锁定条件 | `locking` | 锁定形式、允许调节后是否保持、必要锁定件 |
| 防转条件 | `anti_rotation` | 定位销、止转面、齿盘或阵列；不由螺纹匹配推定防转 |
| 可用空间 | `clearance` | 插入、旋紧、旋转和拆卸所需空间及遮挡条件 |
| 承载条件 | `load_conditions` | 对应姿态下的载荷、力矩或偏心距等已提供限制；未知不填为无限 |
| 必要组件 | `required_components` | 明确类型的连接件引用、数量及功能；不藏进自由备注 |
| 条件证据 | `evidence_refs` | 每项值和条件的原有来源位置、适用范围和修订 |

### 2.2 信号或供电端口

一个实体插座可以承载多种功能，保留一个端口身份，下面分别列功能，不因功能数量复制多个假插座。机械插合关系也不能替代电气能力。

| 中文字段 | 提案键 | 内容及适用条件 |
| --- | --- | --- |
| 端口身份 | `port_id` | 所属器材、位置和真实端口一一对应 |
| 所属器材路径 | `owner_path` | 与安装点相同的完整身份路径和修订 |
| 端口名称 | `label_zh` | 中文名称及原始标记，区分同型的多个端口 |
| 接头规格 | `connector` | 标准、版本、针数、端点形态、键位和锁扣 |
| 功能清单 | `functions` | 视频、音频、供电、同步、控制、数据等逐项能力 |
| 各功能方向 | `direction_by_function` | 输入、输出、双向；供电的取电和供电另列，不能只标一条方向 |
| 各功能模式 | `modes_by_function` | 模式、协议版本、功能子集及适用固件 |
| 并行限制 | `concurrency_constraints` | 哪些功能可同时使用，切换或占用会关闭哪些能力 |
| 必要线缆或转接 | `required_connections` | 对端和中间件的完整引用及所需功能 |
| 逐项证据 | `evidence_refs` | 接头规格和各功能分别绑定证据，不互相借用 |

## 3. 机械安装按类型继续细分

### 3.1 螺纹

不能只存“口径”。相同外径但牙型、螺距或螺纹制不同，不能判为同一接口；转接螺钉有两个独立端点，不能把一端代号抄给另一端。

| 中文字段 | 提案键 | 内容及适用条件 |
| --- | --- | --- |
| 完整螺纹代号 | `designation` | 保留原始规格及明确标准引用 |
| 螺纹制 | `thread_system` | 公制、英制或明确专用定义；未知不能按外径猜 |
| 公称直径 | `nominal_diameter` | 数值及原始单位，转换后的值不覆盖原值 |
| 螺距或每英寸牙数 | `pitch_spec` | 区分螺距和牙数、值、单位；按所属螺纹制适用 |
| 牙型 | `profile` | 已有资料明确的牙型或标准，不由制式推定未给出的特殊差异 |
| 内外螺纹 | `thread_form` | 本端是内孔还是外杆 |
| 旋向 | `handedness` | 右旋、左旋、未知 |
| 可用孔深 | `usable_depth` | 接收端有资料时记录；盲孔总深不冒充有效啮合长度 |
| 外露长度 | `projection_length` | 插入端在所选装配状态下的外露长度 |
| 啮合要求 | `engagement_limits` | 已明确的最小或最大啮合、止挡、垫片条件；不自行补安全阈值 |
| 螺纹精度条件 | `fit_class` | 来源确有说明时记录；不是默认必填实测值 |
| 周边安装条件 | `surrounding_geometry` | 底面、定位孔、防转销和工具空间，引用相应结构 |

未知规格可以保留资料，但自动匹配不能把缺值当通配符；同直径仅是候选筛选，不是已匹配。

### 3.2 无螺纹安装

| 安装类型 | 展开的字段 | 判定范围 |
| --- | --- | --- |
| 卡口 | 卡口身份、版本、凸耳/槽、锁定、旋转方向、插入空间 | 机械锁合；光学、电气、控制各自校验 |
| 附件座 | 标准身份、导轨尺寸、触点、插入方向、锁定方式 | 冷靴式纯机械连接和带触点连接不混为一种功能 |
| 导管 | 管径、管距、中心高度、夹紧范围、单管/双管、允许位置 | 管径一致不代表整个导管系统一致 |
| 夹持 | 被夹持形状、直径或厚度范围、接触面、衬垫、锁紧和载荷条件 | 圆管、平板等条件分别记录 |
| 快拆 | 板与座的身份、系统版本、插入方向、止挡、锁扣、防脱条件 | 类似外形不推为同一快拆系统 |
| 滑轨 | 轨道轮廓、尺寸、可用行程、限位及锁紧 | 调节行程和有效承载位置分开 |
| 专用锁扣 | 官方宿主范围、对应端点、锁定动作、必要组件 | 不通过通用螺纹绕过宿主名单 |
| 磁吸 | 宿主范围、接触几何、方向、防转及适用限制 | 仅记录有资料的成立条件，不推定任意金属表面适用 |

这些分项仍保存来源、状态及单位，不把整套安装条件压成一句中文备注。

### 3.3 支架

| 中文字段 | 提案键 | 内容及适用条件 |
| --- | --- | --- |
| 支撑端 | `base_endpoint_refs` | 连接摄影机、底座、夹具或其他支撑的真实端点清单 |
| 承载端 | `payload_endpoint_refs` | 连接被承载器材的真实端点，与支撑端分开 |
| 调节轴 | `adjustment_axes` | 水平、俯仰、旋转等实际自由度，各轴范围及单位 |
| 锁定机构 | `lock_mechanisms` | 独立锁定或联动锁定，分别关联受控轴 |
| 防转结构 | `anti_rotation_refs` | 各端实际防转结构及所需部件 |
| 有效行程 | `usable_travel` | 调节或滑动行程；限位及装配条件随值记录 |
| 承载限制 | `load_conditions` | 姿态、伸出量、偏心及厂家给出的载荷条件；不只一个重量数值 |
| 组合空间 | `clearance_constraints` | 屏幕翻转、旋钮操作、端口插线和设备开盖等相关空间 |

### 3.4 魔术手臂（怪手）

| 中文字段 | 提案键 | 内容及适用条件 |
| --- | --- | --- |
| 手臂端点 | `endpoints` | 每端独立展开；两端可不同，端头可换时记录可换组件和装配状态 |
| 分段长度 | `segments` | 各段长度及单位，不把总长等同于有效伸展 |
| 关节 | `joints` | 球头、转轴等实际类型，各关节调节范围 |
| 锁紧范围 | `locking_scope` | 一个旋钮锁哪些关节，各端是否仍可独立调整 |
| 伸展条件 | `extension_conditions` | 展开形态、有效距离、干涉范围 |
| 姿态承载 | `load_conditions` | 载荷与姿态、伸出量、力矩等原有条件绑定 |
| 端头限制 | `endpoint_constraints` | 两端规格、可用长度、防转及必要连接件 |
| 装配质量 | `assembly_mass` | 本体及已选择端头的明确测量范围；不修改器材本体重量 |

“支架”和“怪手”有不同的调节和锁定结构，但都使用同一安装点、端点和证据定义。不能因为都能装监视器，就合并成同一个接口。

## 4. 功能支持各自有条件

以下嵌套结构分别用于既有 `power_inputs`、`signal_input`、`control_support_links`、`format_support_links` 等字段。不新增一个能塞所有内容的“万能支持”对象。

| 能力分项 | 必须展开的条件 | 明确区分的结果 |
| --- | --- | --- |
| 光学适用 | 明确宿主、光学位置、有效成像范围、适用焦距或模式、间隙、遮挡及叠加条件 | 机械可装；在指定条件下覆盖；有无已说明的遮挡；作用效果是否有资料 |
| 供电 | 电源端与取电端、电压范围、电流或功率条件、极性、协议、线缆、同时使用及启动条件 | 可接头；可供电；供电功率是否满足；未知分别返回 |
| 视频信号 | 输入/输出、协议及版本、分辨率、帧率、扫描方式、位深、色度采样、色彩解释、带宽及协商条件 | 可显示、可透传、可转换、可录制是不同功能 |
| 音频信号 | 模拟/数字、电平、平衡方式、声道、供电、采样率、位深及模式 | 可插接、可接收、可供话筒电、可录制分别判断 |
| 同步 | 时间码或同步信号类型、输入/输出、帧率或频率、参考源及模式 | 时间码传递、时间基准锁定和画面同步不互相代替 |
| 控制 | 控制发起端、被控端、协议版本、命令子集、固件、必要线缆及中间件 | 对焦、光圈、镜头数据、录制控制、防抖等逐功能判断 |
| 数据 | 读/写方向、协议版本、持续速率、介质或设备限制、并行使用 | 充电连接不推为数据连接；瞬时速率不推为持续记录能力 |
| 格式 | 格式定义、配置版本、编码参数、模式、分辨率、帧率及版本限制 | 输入、输出、显示、录制、转换、导入、导出逐方向记录 |

### 4.1 逐功能结论

| 中文字段 | 提案键 | 记录方式 |
| --- | --- | --- |
| 被判断功能 | `function_key` | 有中文名称，关联明确能力定义 |
| 起点端点 | `from_endpoint_ref` | 器材完整路径、端点及修订；不是品牌或器材大类 |
| 目标端点 | `to_endpoint_ref` | 同上，方向与功能一致 |
| 适用配置 | `configuration_refs` | 变体、模组、模式、固件或软件版本；引用所判断的实际配置 |
| 结论 | `support_state` | 支持、有条件、不支持、未知、不适用，逐功能记录 |
| 未满足条件 | `unmet_conditions` | 已知所需条件和当前差距；不把缺证据说成不支持 |
| 必要中间件 | `required_intermediates` | 每件身份、方向、端点、功能和数量 |
| 否定条件 | `exclusions` | 明确禁用的配置、型号或功能及依据 |
| 证据 | `evidence_refs` | 支持等级、来源类型、位置、条件和修订分别记录 |

不支持必须有否定依据或已知条件冲突。缺少必需值或证据返回未知；已确认不适用的字段才标不适用。空名单不表示支持全部型号。不同来源冲突保留两条条件化断言，列明差异，不以最新时间静默覆盖。

## 5. 每个器材入口怎样接上这些结构

| 器材小类及既有字段 | 展开到的结构 | 本次补齐的边界 |
| --- | --- | --- |
| 摄影机：`accessory_support_links`、`port_links` | 宿主范围、机身安装点、各端口功能、逐功能结论 | 摄影机可用附件清单仍引用各附件自己的小类及型号 |
| 摄影机：`power_inputs`、`lens_mount_interface_id` | 供电端点；原生卡口定义及条件 | 机身孔位不挤进镜头卡口；机身视频输出不冒充内录规格 |
| 镜头：`filter_thread_mm`、`front_diameter_mm`、`lens_mount_interface_id` | 螺纹；前端夹持；镜头卡口 | 滤镜螺纹直径和镜头外径不是同一个安装尺寸 |
| 光学附件：`attachment_site`、宿主支持 | 光学位置、明确宿主、安装端点及光学条件 | 专用增广附件不自动成为所有镜头的候选 |
| 遮光斗：`mounting_method`、`rod_support_links` | 镜头端安装；导管端安装；必要连接件 | 镜头夹持和导管承载可以并存，分别建连接边 |
| 滤镜架：`supported_filter_sizes`、`tray_support_links` | 槽位、片幅、片厚、托盘端点 | 可放入、可锁定、可旋转和遮挡条件分开 |
| 镜头连接环：`lens_end_thread`、`carrier_end_interface` | 两端独立螺纹或夹持结构 | 缩口、扩口或其他实际作用不由名称推兼容 |
| 摄影支撑：`mount_interfaces`、`base_support_links` | 支撑端、承载端、支架或怪手分项 | 同为支撑器材不表示端点、关节和承载条件相同 |
| 快拆组件：`screw_thread`、`system_support_links` | 螺纹结构、板/座系统和锁定 | 拧紧到板上不等于与某接收座匹配 |
| 稳定器：`quick_release_support`、`host_support_links` | 装配空间、板座、重心及承载配置 | 不只看机身重量，完整配置及平衡条件单独记录 |
| 灯具：`support_interfaces`、`modifier_mount_interface_id` | 灯头支撑端；控光端 | 不把控光卡口当灯架接口 |
| 灯光支撑：既有支撑参数 | 支撑点、夹具、导管或插座等实际结构 | 摄影支撑知识可具名引用，型号资料保持本类 |
| 供电设备：既有输入输出 | 每个端口、供电方向、电气条件 | 输入能力不自动成为输出能力 |
| 线缆：既有端点参数 | 各端接头、内部功能、方向、条件 | 同外形插头不推相同接线和带宽 |
| 转接件：`function_passthrough`、宿主支持 | 两侧端点、被动透传或主动转换 | 转接后逐功能重新判断，不沿用机械连接结论 |
| 监看设备：`mount_interfaces`、`signal_input`、`signal_output` | 监视器安装点、支架连接、信号能力 | 机上用途不复制型号；可显示不等于可录制或透传 |
| 视频传输设备：`member_support_links` | 发射与接收身份、各端模式 | 发射器输入模式和接收器输出模式不能合成一条最高值 |
| 音频设备：各输入输出及同步字段 | 真实端口、信号、电源和同步条件 | 同一插座不同功能分项判断 |
| 官方套装：`member_links` | 套装成员及数量 | 随附不证明两两安装兼容，也不合并成员能力 |

这里是字段定义之间的结构引用，没有实际产品配对。具体型号的关系记录必须写出每端所属大类、小类、型号、位置和证据。

## 6. 装配不能只是一条线

机械支撑、视频、供电、控制和光学路径分别表示连接。一个器材可以同时有多条不同性质的连接：机械支撑连接的对象不一定是信号来源；机械路径中间的支架也不一定传电或信号。不能沿一条“摄影机附件链”继承所有能力。

装配记录只引用已有器材身份和端点，不创建新版库存、领用或仓库。实际配对、拍摄使用方式及组合放真实样例或项目配置，不写进分类正文。

校验顺序：

1. 确定真实器材及变体、用途、安装点、端口和必要功能；缺少型号或点位时保留待选择。
2. 专用宿主名单、型号排除和范围先检查；接口相同不能绕过名单。
3. 逐机械连接检查形态、完整螺纹、长度、锁定、防转、空间和已明确的载荷条件。
4. 固定配置检查各节点的承载、伸出量和姿态；所有子件及连线影响按明确配置记录，不改写本体规格。
5. 视频、供电、控制等分别检查各自路径；每段功能、方向和版本都需成立。
6. 返回分项结果及来源。所有必需条件成立才作支持结论；未知分项保留未知，用户可继续登记配置，但不能自动标成已验证兼容。

自动推荐仍遵守既有最多两个实际中间组件的限制；手工记录的完整真实装配可以更长，保留所有成员和条件，不因此扩大自动推荐。共享知识关联不属于装配链，不受这个机械路径限制。

## 8. 字段类型、缺值和修订

| 结构 | 类型和填写条件 | 不允许的默认 |
| --- | --- | --- |
| 型号、安装点、端口和组件引用 | 稳定字符串身份及固定修订；清单为有类型的引用数组 | 用品牌名、自由中文备注或相似外形代替身份 |
| 中文名称和原始标记 | 字符串；中文名称必有，原始标记可缺 | 因没有英文简称而隐藏中文名称 |
| 尺寸、孔深、螺距、角度和载荷 | 有单位的数值、范围或条件化测量；范围注明边界，测量注明对象 | 把未知变成0；把未给最大值当无限；把整机重量当配置重量 |
| 内外螺纹、制式、方向、接口类型和结论 | 受控枚举，逐项允许未知；不适用必须有适用性依据 | 缺值自动选第一项；把输入复制成输出 |
| 点位坐标 | 向量、单位、局部坐标系及参考基准，资料有值时填写 | 从产品图片目测并冒充官方尺寸 |
| 点位阵列 | 成员安装点引用、相对几何、必须同时使用的成员及条件 | 将多个孔位合并为一个任意可替换螺孔 |
| 关节和调节轴 | 每项有稳定局部身份、类型、范围、受控锁定引用 | 将联动锁紧写成每轴都能独立锁紧 |
| 必要组件和端点 | 引用数组、数量、功能和连接方向；确认不需要时明确标记无，未核实时保留未知 | 空清单自动表示不需任何组件 |
| 工作配置 | 型号变体、模组、模式、版本和必要条件的具名引用 | 缺固件或模式默认为全部配置 |
| 证据和修订 | 各断言自己的来源引用、位置、范围、来源类型、核验及访问状态 | 同一页出现过产品就把全部字段标已核实 |

型号本体、安装点定义和条件化支持断言各自保留修订关系，不能因一个安装点调整覆盖整机历史。来源更正只更新受影响断言，实际项目配置仍能回查使用时的固定修订；新结果可以提示重新核对，但不自动替用户更换器材。

以上只明确字段类型和职责，不决定必须为每个结构建独立业务表。实现时沿基础合同的对象准入和从属结构判断；本轮不生成数据库迁移或运行接口。

## 9. 文档级验收及未来实施测试

本轮只核对字段设计和文档引用。以下是以后必须执行的合成测试，不是本轮已通过的器材兼容实验。

| 场景 | 必须看到的结果 |
| --- | --- |
| 摄影机顶部和底部有同规格安装点 | 两个独立位置；分别检查空间、防转和承载条件，不相互覆盖 |
| 监视器有不同安装点，用于机上或独立监看 | 仍是一份监看型号；用途关联不同安装配置，输入、供电单独选择 |
| 螺纹外径相同但螺距不同 | 不报告机械匹配；缺螺距时报告未知，不报告不支持 |
| 螺纹匹配但孔深、外露长度或防转条件不成立 | 明确列出未满足项，不能因“能拧上”通过全部安装检查 |
| 支架两端、怪手两端的规格不同 | 每端独立匹配，关节、锁定和姿态载荷属于本体分项 |
| 外部视频可显示，但录制能力未有证据 | 显示结果单独保存，录制为未知；不抄机身内录参数 |
| 插头可插合但电气条件不同 | 机械连接与供电结果不同，不透传为供电支持 |
| 一根线用于多个功能，但所需功能或带宽未明确 | 未证实功能为未知；不能按端头外形补能力 |
| 机械路径与视频、供电路径不同 | 逐性质显示连接；支架不会被当成视频转接或电源中间件 |
| 专用附件不在明确宿主范围 | 不列为已适配项；无否定证据时说明缺范围证据，不冒充物理不可能 |
| 所需托盘、连接环、夹具或支撑尚未选择 | 必要件直接可见；不在备注中隐藏，不自动补假型号 |
| 同一资料有多个冲突来源 | 保留条件和来源差异，不能默默覆盖或生成一条无条件“支持” |

判定接口还须在实施阶段覆盖预期修订、权限、幂等、删除及迟到结果；不能仅因这张表存在宣称完成接口或兼容功能。
