# 下一代需求基线与旧约束替换

2026-10-05。依据：总纲3.3、知识需求2.1、工种目录1.0及本会话最新确认。这里只提取产品合同，不继承旧实现、进度、资产或数据；来源固定于[清单](sources/SOURCE_INDEX.md)。

## 最新决定

| 决定 | 下一代含义 |
| --- | --- |
| 规划只用于下一版本 | 文档继续完善，明确启动从零重构后才实施；不是本版本修改依据 |
| 不保留现有任何资产 | 旧代码、UI、组件、模板、用户工程数据和媒体不纳入；空库和新存储开始 |
| 取消项目整行封面约束 | 入口重新设计，旧整行照片和渐变不再是验收条件 |
| 单独目录、另一个分支 | `next-generation/`，`docs/next-generation-plan`；不混入当前工作包 |
| 旧“功能基线”无效 | 不执行旧 Golden Baseline 的恢复/对等要求；来源提交仅作出处，最新有效需求逐项审阅 |

这些决定覆盖旧总纲 D-18 中保留封面/已明确界面、旧构图弹窗几何和旧服务复用/迁移细节。图片不拉伸、固定构图、权限、历史、列模型等行为合同仍有效，如何呈现重新设计。使用第三方轮子不等于复制旧实现。未授权物理清除旧环境。

## 保持的业务范围

项目独立授权；账号/项目现实人员/剧情角色分离；场景镜头多关系、动态继承和逐项覆盖；全项目创作提交、镜头比较和独立执行/审阅历史；九基础列、按需预设、自定义列、共享视图、可逆编辑和确认永久删除；资产、构图、缩略图、二维三维灯光、情绪板与旁白 TTS；Excel/PDF/OCR 导入预览、映射、覆盖或添加；模块化导出与授权链接。

主制作链保持场景/镜头 → 任务/主责 → 档期/排期 → 转场 → 通告 → 实际 → 固定素材交接 → 后期 → 审阅/返工/补拍 → 交付 → 经验校准。组织对象、真实业务连接、版本和权限各自负责人，不因一张界面需要就复制事实。新一级对象准入与真实父子规则见 AGENTS。

不恢复库房、库存、预留、采购、预算、财务、复杂耗材、操作教程、空拍摄条次页、独立 duplicate 和归档。时间段需求独立相加、明确共用一次；型号知识不推断本次可用量。默认项目时区北京时间，可明确配置。

## 需要重新设计而不是重新确认的行为

业务字段仍区分真实零、空、未知、不适用；单位、稳定分类键和连续值分别处理。计划、基线、预测、实际和实际更正独立，片长与拍摄时长分开。数据字典是来源语义，不是旧 ORM 要照抄的理由。

作业、通知、确认、交接、权限和下载都有独立真实状态，不能由按钮变色制造事实。一键生成草稿/预览可以；发布、对外发送、永久删除仍是明确有权动作。全站本地草稿和异步保存只在服务端确认后显示已保存，冲突保留输入。

## 尚未确认事项

工种目录 J-01—J-08 保持未决：添加岗位授予谁、团队岗位与项目部门关系、目录自定义和停用权限、来源变化的版本处理、团队/机构统计、跨团队授权、默认启用岗位及内容方向/标签/制作方式关系。不能从“全部重构”推断已批准这些选择。无关模块可以继续规划，这些部分在相应实施前询问。

新版原生工程导入导出需要新格式合同；不以旧工程兼容作为首版门槛，也不自动迁入旧数据。此前要求的“易于打开”、工程 PDF、二维码/DM 和媒体清单继续作为功能目标。
