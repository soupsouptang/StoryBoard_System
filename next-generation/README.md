## 启动条件

先明确启动下一代重构，确认首批范围和技术方案；检查届时最新需求及其他 agent 的分支，登记允许写集、集成负责人、协议、数据库起始方案和验收入口。当前版本服务继续独立运行；本计划不授权清空或删除它的数据库、文件、截图、备份和配置。

UI实施顺序为先重构并验收对应的新架构、数据、命令与权限基础，再开始页面实现。现在继续存放和修改UI设计文档，重构与界面开发都未开始。

旧用户数据不纳入新版，与物理销毁旧数据是两回事。本轮只生成新文档；未来若需要删除旧环境，必须明确目标和删除范围再执行。新版仍保留用户主动导入新工程的业务功能，但不能自动扫描或搬入旧工程、旧媒体或旧凭据。
