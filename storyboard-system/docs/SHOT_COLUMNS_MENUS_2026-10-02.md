- 表格展示、列混排、宽度、显示别名及复制显示格式：`apps/web/lib/shot-table-presentation.ts` 与分镜页面现有展示状态；旧缓存/旧 SavedView 的四列键会过滤。
- 新增/改名弹窗：根 `@frameforge/ui` Dialog/Input/Button；候选顺序按现有目录，不按勾选点击顺序重排。
- 自定义定义/值：`CustomFieldService`、既有 `CustomFieldDefinition`、`ShotCustomFieldValue`、`ColumnPreference`；批量新增/恢复与整列复制走各一个 API 事务，路由不写 SQL。
- 整列复制：权限 → 项目锁 → 完整活动 Shot 锁 → 来源定义锁 → revision 校验 → 新定义和值 → revision/审计 → 提交后回执。连续粘贴用本次回执 revision 更新剪贴板，其他写入导致 409 时保留原数据并提示重新复制。
- 剪切只是原列的位置变化；不使用删除/重新创建。系统剪贴板保存当前项目的列身份及 revision，不携带整列业务内容。输入框保留原生文本快捷键。
- 列布局继续使用现有本地展示偏好；点击“保存视图”通过既有 `SavedViewService` 保存混合列顺序、别名、格式、列宽、换行、筛选和排序。“全员实时共享视图”仍是数据库方案待办，不能把本轮保存/应用视图宣称为自动同步。
- 没有新增依赖、DDL、Legacy 数据迁移、部署或生产数据操作。数据库计划仍需单独确认。
