## 页面及状态清单

- 项目大厅：整行图片封面、暗色渐变、标题/类型/镜头数/时长/FPS/比例、更新时间/操作者、编辑/打开；无封面、搜索空结果；管理员用户管理。
- 表格：只有基础列的默认布局；无批注隐藏整列；单选、Shift 区间、Ctrl/Cmd 多选、全筛选集全选；行内草稿、IME、失败保留；列宽/行高/自动尺寸、冻结/横滚。
- 列管理与筛选：入口可发现、Popover 完整可见；基础/预设/自定义/回收站；隐藏不删数据、删除可恢复、永久删除先确认并说明影响数量。确认取消必须不发起删除。右键列头、单元格、单镜头、多镜头各自截图；菜单可关闭并归还焦点。
- 卡片/视觉墙：同一镜头的图、TC、时长、状态和选中状态与表格一致；完整可读描述/旁白；无图真实占位；竖版图框、contain 黑边。
- 时间线：实际分镜图预览、当前镜头摘要、播放/定位、按篇章分组、真实总时长；不能用文字卡替代已有画面。
- Inspector：读视图分区与字段完整，按需编辑；制作步骤、自定义字段、多画面排序、版本/批注入口；不让常驻危险按钮挤占阅读区。
- 审片：媒体中心三栏，选区/字段/画面锚点、回复/引用、已读/未读、版本及 Before/After；链接权限/期限/撤销/字段裁剪。
- 素材：真实缩略图/类型/大小/引用；上传、替换、裁剪、进度/重试；未使用过滤、受引用删除限制。
- 情绪板与灯光：左库/中央画布/右属性、底部工具；共享 2D/3D 对象与分屏；存取、关联分镜、撤销重做、右键对象操作。
- 旁白：受控语速滑杆、可播放 TTS 样例、预计/实测时长、锁时长例外、按镜头及批量计时。
- 导出/导入：六种基线 PDF 版式、横/竖 PDF、Word、好莱坞剧本、工程 PDF/便携包；字段/镜头范围/预览；可见水印 CRUD、隐写检测；QR/DM 重组再导入。真实文件另验，禁用按钮不算完成。
- 项目设置：独立页整合标题/FPS/比例/封面/共享状态；创建后可改竖版；用户管理管理员限定。

## 行为与后端证明

只采图不能证明保存成功。对改动的功能补定向验证：编辑后刷新、第二用户看到同一共享视图、revision 冲突不吞草稿、取消永久删除无变更、确认删除后旧快照/缓存/工程导出不可恢复被删业务值。不可见水印必须有编码/解码以及裁剪/截图样本的识别率和误报率，不以元数据代替。

本轮不运行大测试套件；新增破坏性数据操作应在隔离数据中验证。普通截图记录不得声称上述所有后端场景均已运行。

## 判定规则

核心页面布局错、功能入口缺、假动作、字段丢失、保存/同步失败、图拉伸或时码不一致任一存在即 FAIL。未跑项写 NOT_RUN，不推断 PASS。所有核心桌面页面及其对应持久化/同步证明通过后才允许讨论 cutover；Legacy 的真实消费者迁移完成前不能清理旧 owner。
