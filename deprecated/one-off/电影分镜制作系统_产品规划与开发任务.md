# Plan

建设一套单公司私有部署、面向国际专业影视管线的电影分镜制作系统，以“帧级时间线 + 结构化镜头 + 多类型制作模板 + 素材版本 + 审片交付”为核心，同时适配电影、纪录片、TVC、MG 动画及 3D/VFX 制作。系统采用“外网仅负责访问入口、公司内网服务器保存并处理全部数据”的分离架构；外网只承载通用静态应用壳和密文通道，项目、账号、权限、镜头、版本、日志、导出文件及全部媒体代理均位于公司内网。图片和视频由客户浏览器生成高清审片代理后上传内网存储。系统当前不启用 AI，但所有脚本拆镜、语音对齐、图像生成、素材搜索和视频预演能力均通过稳定的 Provider 接口预留，确保未来接入时不改动核心数据模型。

## Scope
- In: 单公司单租户私有部署；外网域名入口、通用静态应用壳与无状态密文转发；公司内网部署认证、权限、核心 API、PostgreSQL、对象存储、代理文件、审计、分享、导出、备份和监控；内网节点主动建立加密出站通道；浏览器端图片与视频压缩、清晰度校验、缩略图和分片上传；电影、纪录片、TVC、MG、3D/VFX 项目模板；卷/序列/场/镜头层级；SMPTE 帧级时码；旁白、字幕与音频轨道；按文字、标点和目标片长自动分配镜头时间并支持手动修改；Storyboard 表格、卡片和时间线；素材与版权管理；版本、审批与审计；内部账号权限；无账号只读审片链接及默认永久下载；Excel 上传自动识别表列；PDF、Excel、CSV、JSON、SRT/VTT、OTIO、EDL、FCPXML 等交换与交付；AI 扩展接口。
- Out: 外网节点不得保存任何公司业务数据，包括项目元数据、账号资料、权限、会话、分享令牌、审计日志、图片、视频、媒体代理、缩略图、导出文件和下载包；仅允许保存可公开重建的前端静态代码、无业务内容的运行配置及不含 URL 路径/令牌的最小网络健康指标。分镜系统不保存拍摄母版、无压缩原片和最终交付母版，只保存适合导演审片、分镜预览和下载的高清代理文件。当前阶段不提供实际 AI 推理服务，不替代 Premiere Pro、Avid、DaVinci Resolve、After Effects、Maya、Blender、Cinema 4D、Houdini 等专业制作软件，不承担最终剪辑、调色、混音、渲染农场、财务结算、演员管理和完整制片排期；移动端以审片和轻量查看为主，不开发原生 App。

## Action items
[ ] **01｜定义专业制作标准与项目模板（P0）**：建立统一的 Production → Reel/Episode → Sequence → Scene → Shot → Version 层级，并为五类制作分别定义字段与工作流。电影模板包含内外景、日夜、场次、覆盖镜头、连续性、VFX、场记及剪辑状态；纪录片模板包含采访、原素材时码、逐字稿、档案来源、事实核查、版权和 B-roll；TVC 模板包含 5/6/10/15/20/30/45/60/90 秒版本、产品卖点、Packshot、字幕法务、安全框和横竖版适配；MG 模板包含 Styleframe、图层、关键动作、转场、节拍、字体与品牌规范；3D/VFX 模板包含镜头相机、传感器、焦段、Frame Handle、Layout/Animation/FX/Lighting/Render/Comp 状态、资产版本和渲染参数。验收标准：同一制作中可混用模板，公共镜头字段一致，类型专属字段可配置且不会污染其他项目。

[ ] **02｜建立帧级时码与旁白自动计时引擎（P0）**：所有时长以整数帧存储并派生显示秒数，支持 23.976、24、25、29.97 DF/NDF、30、48、50、59.94、60 fps；项目默认起始时码固定为 `01:00:00:00`，仍允许管理员在模板或项目中调整，并支持 Drop-frame 规则、Frame Handle、目标总时长和镜头锁定。系统不依赖音频识别或字幕时码，仅根据每个镜头的中英文旁白文字量、逗号/句号/问号/感叹号/省略号等停顿权重、段落权重、最短时长、最长时长和项目目标片长分配镜头时间；无旁白镜头使用可配置基础时长。用户可直接修改单镜时长、TC IN 或 TC OUT，并选择锁定；系统只在未锁定镜头间重新分配剩余时间。修改旁白、目标片长、镜头顺序、拆分或合并镜头后自动重算累计时码，TVC 可严格锁定 15/30/60 秒等交付长度并显示误差来源。验收标准：任意支持帧率下无累计漂移，Drop-frame 计算符合 SMPTE 规则，所有镜头帧数之和严格等于目标片长，手动修改并锁定的镜头不被自动覆盖，自动分配前后均可撤销和恢复。

[ ] **03｜设计“外网仅入口、内网保存全部数据”的分离架构（P0）**：外网节点仅部署可公开重建的静态应用壳、DNS/TLS 入口、四层加密转发和隧道连接协调，不运行认证、业务 API、数据库、分享服务、审计服务、导出任务或对象存储；公司内网数据节点部署认证与权限、核心 API、PostgreSQL、S3 兼容对象存储/NAS 适配器、缓存/队列、导出 Worker、分享令牌、审计日志和监控。内网 Connector 主动向外网入口建立 mTLS/WireGuard 类加密出站通道，不要求公司开放入站端口；业务 API 与媒体域名使用 TLS Passthrough，TLS 在内网网关终止，外网只看到连接元数据和密文字节。内部员工可直接访问内网地址，外部员工和匿名访客通过同一入口转发至内网；内网节点离线时外网页面只显示“公司内网服务暂不可用”，不得读取历史缓存。建立 productions、deliverables、reels、sequences、scenes、shots、shot_versions、tracks、cues、assets、asset_versions、people、comments、approvals、share_links、exports、audit_logs、integration_jobs 等实体，全部落在内网 PostgreSQL 和对象存储。验收标准：对外网服务器进行磁盘、内存转储、日志、数据库端口和备份扫描时不存在任何业务数据或媒体代理；重建或删除外网节点不影响内网项目；外网节点被攻陷时不能读取业务明文；内网节点可用单机 Docker 部署并保留多节点扩展能力。

[ ] **04｜实现专业 Storyboard、时间线与镜头编辑工作台（P0）**：提供电影卡片版、横向宽表、分镜墙、时间线、旁白对照和导演审片六种视图，共享同一实时数据；支持虚拟滚动、拖拽排序、镜头拆分/合并/复制、批量编号、批量改状态、列预设、筛选分组、撤销重做、自动保存、快捷键和全屏看片。画幅支持 2.39:1、1.85:1、16:9、4:3、9:16、1:1 及自定义比例，显示 Action Safe、Title Safe、中心线、三分线、字幕区和平台裁切预览。镜头字段覆盖画面描述、动作、表演、构图、景别、机位、镜头高度、角度、运镜、摄影设备、传感器、焦段、光圈、景深、帧率、快门、灯光、声音、旁白、对白、字幕、音乐、音效、转场、VFX/3D、连续性、风险和审批状态。验收标准：万镜级制作可按序列加载和编辑，常用操作可由键盘完成，断网恢复不静默覆盖较新版本。

[ ] **05｜建设浏览器高清压缩与客户本地素材库（P0）**：图片和视频在客户浏览器内完成读取、方向校正、色彩空间归一、缩放、编码、质量检测、缩略图生成和压缩后哈希计算，再使用短期签名凭证分片上传本地对象存储；外网节点仅中继密文流且不得落盘。照片类图片默认生成长边不超过 2560 px、展示尺寸不低于 1920×1080 的 WebP/AVIF 高清代理，编码质量建议 0.85–0.90；源文件低于目标尺寸时不得放大。带透明通道、线稿、字幕、表格或 UI 截图自动使用 PNG/WebP 无损或近无损策略，避免文字和细线糊化。视频默认生成最高 1080p、H.264 MP4 或兼容 WebM、4–10 Mbps 自适应码率、2 秒关键帧间隔和 AAC/Opus 审片代理；优先使用 WebCodecs，缺少编码能力的浏览器使用受控 WASM 转码回退，并提供进度、暂停、取消、失败重试和内存保护。系统默认只保存压缩代理，原始图片和视频保留在用户原有生产存储中，不上传本系统。其余 PDF、字幕、字体、LUT、3D 模型、贴图和工程包按原文件上传。素材库记录版本、镜头引用、来源、作者、授权范围、期限、地区、平台、合同编号和下载限制。验收标准：压缩前在浏览器执行分辨率、文件体积、SSIM/像素差异和测试图可读性检查，未达到阈值时自动提高质量或阻止上传；1920×1080 显示环境下标准审片测试图、中文小字、线稿和暗部视频细节清晰可辨；断点续传不会重复产生素材版本。

[ ] **06｜实现版本控制、审批和无账号审片交付（P0）**：内部员工使用管理员、制片、导演、摄影、美术、动画/VFX、剪辑、声音、法务、审片和只读角色；账号、权限、会话和全部写操作仅保存于公司内网。建立镜头级和项目级版本、命名快照、差异对比、审批流、退回原因、冻结版本和可恢复回滚。生成由内网服务签发、验证和撤销的不可猜测 Share Token；访客无需账号即可通过外网入口只读查看内网发布的指定冻结版本，并从内网存储下载 PDF、Excel、高清代理图片、代理视频或交付压缩包。分享 URL 使用浏览器 Fragment 或一次性引导方式，避免令牌进入外网访问日志；访客不能编辑、评论、查看草稿和访问其他项目。默认安全策略为“永久有效、允许下载”，发布者可主动增加有效期、访问密码、IP/次数限制、动态水印或关闭下载。外网入口不验证、不保存令牌和文件，只流式转发端到端加密连接；内网离线时分享页显示暂不可用。验收标准：撤销链接立即失效，分享版本后内部修改不会改变访客看到的冻结内容，所有匿名查看和下载均由内网记录链接、时间、IP、文件与结果，外网入口重启后不存在会话、令牌或媒体残留。

[ ] **07｜建立 Excel 智能识别、专业交换格式与连接器预留层（P0）**：Excel 上传支持 XLSX、XLS、CSV，多工作表扫描后自动判断有效表格和表头行，通过标准字段词典、中文/英文别名、模糊匹配、数据类型、示例值和列内容识别镜号、场次、篇章、旁白、画面描述、时长、TC、景别、焦段、运镜、声音、VFX、素材路径等列；对合并单元格、空列、重复列、公式值和多级表头提供预览与人工确认，低置信度字段不得静默导入。提供 JSON Schema 作为系统主交换协议，并实现 Excel/CSV/PDF/打印、SRT/VTT/ASS、OpenTimelineIO、CMX EDL、FCPXML 适配器；AAF、Avid ALE、Premiere/After Effects、DaVinci Resolve、Blender、Maya、Cinema 4D、Houdini 和 ShotGrid 风格连接器只预留接口，不列入当前实机兼容承诺。验收标准：不同命名、顺序和中英文字段的样例表能够自动完成高置信度映射；导入前显示新增、更新、忽略和冲突数量；标准格式使用公开规范、Schema 校验器和固定测试夹具完成往返测试，不要求任何制作软件实机测试。

[ ] **08｜预留可插拔 AI 与自动化 Provider 接口（P1）**：定义统一的 Capability、Provider、Model、Job、Input Asset、Output Asset、Progress、Cost、Safety、Provenance 和 Error Contract，不在核心业务中硬编码任何厂商；预留 screenplay_breakdown、voice_alignment、speech_to_text、image_search、storyboard_image_generation、image_edit、video_previsualization、copyright_scan 等能力。所有 AI/自动化任务使用异步队列、幂等键、取消、重试、超时、预算上限和人工确认；结果必须作为新素材版本进入审核，不得直接覆盖人工批准内容。当前部署默认禁用全部 Provider、不开外网权限，系统在无 AI 配置时所有核心功能正常。验收标准：通过 Mock Provider 完成接口契约测试，未来增加厂商只需新增适配器和配置，不修改镜头、时间线和素材表结构。

[ ] **09｜完成质量、安全、压缩与数据零驻留测试（P0）**：为时码、Drop-frame、文字与标点权重分配、目标片长约束、手动时长修改、锁定镜头重排、Excel 列识别、跨帧率转换、版本冲突、权限、匿名分享、下载审计和格式往返建立单元及集成测试；为照片、线稿、透明图片、中文表格、暗场视频、快速运动、不同帧率和长视频建立浏览器压缩黄金样例，覆盖 Chrome、Edge、Safari、Firefox 的 WebCodecs 与 WASM 回退路径。验证外网入口与内网数据节点隔离，对外网进程内存、交换分区、磁盘、临时目录、访问日志、错误日志、崩溃转储、指标系统和备份执行敏感数据扫描，确认不存在账号、项目字段、Share Token、文件名、缩略图和代理文件；模拟内网断网、隧道重连、分片中断、对象存储满、浏览器内存不足和匿名下载并发。进行 OWASP 基线、越权、路径遍历、恶意文件、限流和依赖扫描。验收标准：帧级黄金测试、Excel 识别样例和媒体清晰度基线全部通过，代理文件在目标显示尺寸清晰可审片，全部业务数据与代理只在内网可找到，匿名用户只能读取已发布范围，10,000 镜与 100,000 素材基准达到约定响应指标，关键故障均有可验证恢复路径。

[ ] **10｜分阶段上线外网入口与公司内网完整数据节点（P0）**：按“外网静态入口/密文转发 → 内网认证/API/数据库/对象存储 → 加密出站 Connector → 帧级工作台 → 浏览器媒体压缩 → 内网审批分享 → 专业交换”七阶段发布，每阶段使用真实电影、纪录片、TVC、MG 和 3D 样例验收。外网节点仅配置静态应用发布、L4 TLS Passthrough、DDoS/连接限流、无状态扩容和不记录 URL/请求体的最小健康指标，不配置业务数据库、会话存储、对象存储或业务日志；公司内网节点配置本地账号/SSO、全部业务服务、数据与代理加密、数据库和对象存储增量备份、异地备份、监控告警、容量预测、Connector 自动重连、证书轮换和一键回滚。外网节点不制定业务数据备份，只保留可从代码重建的基础设施配置；所有 RPO/RTO、灾难恢复和合规留存以内网数据节点为准。交付双端部署手册、网络端口清单、数据流图、威胁模型、零驻留验证报告、媒体压缩规范和离线故障说明。验收标准：外网节点可随时销毁并从空服务器重建；销毁外网节点不会丢失账号、项目、版本、分享链接、日志或代理文件；内网全量恢复后系统完整可用；AI Provider 保持禁用但契约测试可运行。
