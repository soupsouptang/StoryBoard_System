# FRAMEFORGE CSS OWNERSHIP MAP

## 1. Background & Principles
The codebase has multiple CSS stylesheets loaded in `static/index.html`:
- `/workspace-ux.css`
- `/creative-boards.css`
- `/workspace-v73.css` (Generated by build.mjs from `src/workspace/theme.css`)
- `/workspace-v73-views.css`
- `/workspace-flow.css`
- `/workspace-flow-pages.css`
- `/workspace-assets-v75.css`
- `/workspace-editor-v75.css`
- `styles.css`

Cascading conflicts frequently occur where multiple stylesheets style the same component (e.g. search bar, sidebar items, text selection). Rule: No component should be overridden by 3+ stylesheets; converge towards the single recommended source. Never use ad-hoc `!important` to patch conflicts.

## 2. Component Ownership Mapping

| Scope / Component | Sole Recommended Source | Notes / Guardrails |
|---|---|---|
| **Workspace Shell / Sidebar / Toolbar** | `src/workspace/theme.css` + React TSX | Build with `node build.mjs`. Never edit `static/workspace-v73.css` directly. |
| **Global Legacy Base & Layout** | `static/styles.css` | Login, base resets, global container structure. |
| **Global Search Bar** | `static/styles.css` | Outer shell only. Child inputs must be transparent with no inner borders. |
| **Creative Boards / Moodboard / Lighting Canvas** | `static/creative-boards.css` | Canvas containers, board tools, floating toolbars. |
| **Lighting 2D / 2.5D / 3D Layout & Inspector** | `static/creative-boards.css` & `static/lighting-assets.js` | Equipment library panel, inspector dock. |
| **Legacy UX Patches (Cross-cutting)** | `static/workspace-ux.css` | Restrict strictly to bug fixes (e.g. text selection, popovers). Converge and deprecate redundancies. |
| **Flow Pages & Process** | `static/workspace-flow*.css` | Flow tabs and stage views. |
| **Asset Library Views** | `static/workspace-assets-v75.css` | Grid cards, filters, previews. |
| **Shot Editor & Table Inspector** | `static/workspace-editor-v75.css` | Table cells, inline editors, shot inspector drawer. |

## 3. Input & Text Selection Rules
- Inputs, textareas, `[contenteditable="true"]` must have:
  ```css
  user-select: text;
  -webkit-user-select: text;
  cursor: text;
  ```
- Buttons, handles, menus, select controls must have:
  ```css
  user-select: none;
  ```
- Temporary drag/resize states (`is-resizing-*`) must properly clear upon `pointerup`, `pointercancel`, `lostpointercapture`, and `window.blur`.
