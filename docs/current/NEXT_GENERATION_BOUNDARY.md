# 当前版本与下一代边界

旧功能基线失效，不再要求按旧提交/页面/能力对等表恢复功能。用户逐条确认的有效需求不因取消基线而失效；冲突时以最新明确决定为准。

当前 `master` 保留真实 Web、API、Worker、数据库迁移、共享包、部署配置和有效测试。不从下一代提案反向改当前界面，不移动实际运行数据或其他 agent 草稿。当前明确接受的 UI 及 `montblanc08` 最新变更仍须保护。

下一代只在 `docs/next-generation-plan` 的 `next-generation/` 编写方案；尚未开始实现。所有旧实现、UI、模板、数据、媒体和工程都不纳入新版；项目入口重新设计，不要求旧 API、旧数据库、旧文件桥兼容。成熟第三方依赖可重新选型。

`deprecated/` 内的旧程序、规则、迁移路线、基线与旧状态只供回查，不参与正常构建、部署或测试。历史 source-plan 中与空库、无旧资产、取消封面冲突的条款无效，不能被链接重新激活。

明确启动下一代、核查需求与未决项、登记新写集和集成负责人后才实施；不得将下一代方案直接合回当前版本执行清单。
