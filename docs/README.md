# 文档入口

正常入口只包含当前版本事实与边界，旧功能基线已废止。

| 文档 | 职责 |
| --- | --- |
| [版本边界](current/NEXT_GENERATION_BOUNDARY.md) | 当前运行、下一代规划、弃用存档三者分开 |
| [续作入口](current/CONTINUE_WORK.md) | 本轮状态、未提交工作、真实检查和后续边界 |
| [当前架构](current/ARCHITECTURE.md) | 实际入口及仍有消费者的代码 |
| [协作账本](current/ACTIVE_WORKSTREAMS.md) | 当前允许写集，不继承旧工作包 |
| [模块负责人](current/CANONICAL_OWNER_MATRIX.md) | 当前唯一职责归属与验证边界 |
| [前后端交接](current/BACKEND_FRONTEND_HANDOFF_2026-10-04.md) | 保留的未提交草稿及待整合位置 |
| [仓库审计](current/REPOSITORY_CLEANUP_2026-10-05.md) | 本轮分类、移位与待确认问题 |
| [逐文件清单](current/REPOSITORY_INVENTORY_2026-10-05.json) | 每个已跟踪文件的分类、去向、原因和校验值 |
| [弃用存档](../deprecated/README.md) | 历史原件，不作为执行或验收要求 |
| [下一代方案](https://github.com/soupsouptang/StoryBoard_System/tree/docs/next-generation-plan/next-generation) | 另一个分支，当前只规划 |

`current/` 中其余带日期的文件是当前版本已确认行为、实施记录或格式合同。它们不授权按旧进度自动实施新功能，也不要求下一代复制现有 UI/服务。历史结果只对注明的提交负责。
