# FrameForge shared UI

`@frameforge/ui` is the current shared UI source for `apps/web`, using shadcn/Radix, Tailwind semantic colors, CVA variants and Lucide icons. The old functional baseline is invalid. Follow current user-approved UI and verified consumers; do not recover features from a retired commit or copy old CSS. This package is part of the current application, not a code asset for the next generation.

- `src/components/`: shared Button, Input, TextArea, Card, Badge, Dialog, Popover and DropdownMenu source. Keep shadcn's standard variants and radius/padding proportions.
- `src/primitives.tsx`: existing package API; Button/Input/TextArea now re-export the shared components. IconButton adds an accessible tooltip. Field and controlled Select use the same semantic theme while preserving the current caller contract.
- `src/lib/utils.ts`: shared `cn` helper.
- `src/index.ts`: public primitive/icon API. Product copy and locale dictionaries live in `apps/web`, not in this primitive package. V-Web imports shared UI from this package, not a parallel `components/ui` directory.

Both `apps/web/components.json` and this workspace's `components.json` are recognized by the official CLI. The package exports point TypeScript and the CLI to `src/components` while runtime imports use the compiled `dist`. Before adding a component, inspect `npx shadcn@latest add <name> -c apps/web --dry-run`, then verify that the target path is this package's source and review the diff. Run the package and Web builds after changes. The old parallel UI package is retired under `deprecated/`; it is not a runtime, design requirement, or source for next-generation components.

## Consumer compatibility checks

`npm test --workspace=@frameforge/ui` builds the package and checks the controlled Select adapter's empty domain option, collision handling, unchanged native form value, scroll controls and controlled Dialog focus return. Dialog combines consumer autofocus callbacks, respects preventDefault, and returns focus to a still-connected opener, including the stable opener before a transient menu. If the opener no longer exists, Radix retains its default close behavior. Radix reserves `value=""` for clearing; the adapter encodes only the empty menu item and returns an empty domain value to the caller. An empty selection displays its option label as the placeholder, with no selected item indicator.

The latest user decision adopts the [official New York v4 registry](https://github.com/shadcn-ui/ui/tree/main/apps/v4/registry/new-york-v4/ui), Tailwind 4 and 36px default Button/Input/Select controls. Shared primitives now use its geometry, variants, data slots, invalid/focus states, Lucide sizing and overlay motion. The existing controlled Select and TextArea aliases preserve domain consumers; the composable API is available as SelectRoot/SelectTrigger/SelectContent and Textarea. Existing heading semantics and Chinese close copy remain. NativeSelect follows the same control geometry while retaining native bulk-form behavior. Field remains a label composition helper. Built-in focus, keyboard and portal behavior comes from Radix. Rendered focus/return, overflow, scrolling and motion evidence remains `BLOCKED_VISUAL`; source checks do not prove product or visual parity.

Web font assets supply Satoshi 400/500/700 and Unicode-split Sarasa Gothic SC 400. Both UI and historical `font-mono` consumers use the approved Satoshi/Sarasa stack, with tabular numerals; no unshipped Sarasa Term or system monospace family is claimed. Chinese bold still uses browser synthesis because only Sarasa regular is bundled.
